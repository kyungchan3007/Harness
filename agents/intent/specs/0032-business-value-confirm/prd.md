# 0032 — 업무 값은 (가정) 금지, (확인 필요)가 남으면 멈춤 — PRD

- **이슈:** #46
- **문제:** 0025의 "애매한 곳·가정" 필수 칸은 표시만 요구한다. 기존 실험 AM·BM 6회에서 `(확인 필요)`는 2줄뿐이었고 둘 다 구현 세부였다. 쿠폰 감소율·VIP 배율 같은 업무 값은 전부 `(가정)`으로 적고 지어냈다. 그래서 "`(확인 필요)`가 남으면 멈춤"만으로는 거의 아무것도 못 막는다.
- **목표:**
  1. 0032부터 업무 값(금액·비율·배율·끝수 처리) 줄은 `(가정)`으로 둘 수 없게 한다. `(확인 필요)` 또는 `(확인됨: 답)`만 허용.
  2. `(확인 필요)`가 남아 있으면 코드 수정을 막고 완료 검사도 실패시킨다.
  3. 기존 실험 prd에 새 규칙을 돌려, 정답표 항목 중 "가정으로 지어냄"을 몇 개 잡는지와 오탐을 잰다.
- **비목표:** 새 모델 실행으로 행동 변화 측정, `(확인됨: 답)`을 대화 기록과 대조.

## 애매한 곳·가정
- 업무 값 판별 방법 — 줄 글자로 판별, 낱말 목록은 sdd 접근 1 (가정: 모델이 스스로 붙이는 "업무/구현" 표시는 지어내기와 같은 이유로 믿기 어려움)
- 오탐 처리 — 구현 세부가 업무 값으로 잡혀도 빠져나갈 표시는 두지 않음 (가정: 오탐의 대가는 질문 하나, 0028에서 묻는 비용은 작았음)
- 적용 시작 — 0032부터 (가정: 0025~0031 기록은 그 시점 규칙으로 통과한 것)
- 답 표기 — `(확인됨: 답)`, ClauseLens #182와 같은 모양 (가정)
- 재채점 대상 — 애매한 곳 칸이 있는 실행(AM·BM)의 정답표 "assumed" 판정 항목 (가정: 칸이 없는 실행은 새 규칙이 볼 줄이 없음)
