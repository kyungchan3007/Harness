# 0032 — 업무 값 확인 강제 — SDD

요구사항: [prd.md](prd.md)

## 설계
- **읽은 문서:** 0025 sdd(필수 칸), 0030 sdd(흔하지 않은 의도), `agents/harness/hooks/lib/records.mjs`의 `checkAssumptions`·`inspectTask`·`decideEdit`, 실험 기록 `experiments/ambiguity/runs/*/prd.md`·`judgment.json`
- **접근:**
  1. `checkAssumptions(prdText, id)`: id가 0032 이상이면 줄마다 엄격 규칙
     - `(확인됨: 답)` → 통과
     - `(확인 필요)` → "사람 답이 필요" 문제 (묻고 `(확인됨: 답)`으로 바꾸라는 안내)
     - `(가정)`인데 업무 값(`BUSINESS_VALUE`) → "업무 값은 가정 금지" 문제
       - 업무 값 낱말: 숫자+단위(%·퍼센트·배·원·포인트·점), 비율 낱말(할인율·적립률·배율 등), 금액·요금·수수료·한도, 끝수 처리(반올림·내림·올림·버림)
     - `확인 필요`는 괄호 없이 써도 "남은 질문"으로 본다
     - 그 밖의 `(가정)` → 통과
  2. 별도 차단 코드 없이 기존 경로를 탄다: `checkPrd` → `inspectTask` → `decideEdit`(코드 수정 차단)·완료 검사·Stop 점검
  3. 재채점 스크립트 `experiments/ambiguity/strict-retro.mjs`: AM·BM 실행의 prd 줄과 `judgment.json`의 `assumed` 항목 `flagQuote`를 맞춰, 업무 값으로 잡힌 비율과 정답표 밖 줄의 오탐을 센다
- **대안·트레이드오프:**
  - 줄마다 모델이 `[업무]`/`[구현]`을 붙이게: 지어내는 모델이 표시도 지어냄 → 글자 판별
  - `(확인 필요)`만 멈춤: 기존 기록에서 거의 안 쓰여 효과 없음(이슈 배경) → 업무 값 가정 금지까지
  - 오탐 탈출 표시(`(가정·구현)` 등): 모델이 쉽게 씀 → 두지 않음, 대가는 질문 하나
- **파일 계획:** `agents/harness/hooks/lib/{records.mjs, records.test.mjs}`, `agents/intent/templates/prd.md`, `agents/harness/guardrails.md`, `experiments/ambiguity/strict-retro.mjs`
- **위험:** 판별 낱말이 넓어 구현 세부도 막음 → 재채점에서 오탐을 세어 적음. 모델이 `(확인됨: …)`을 지어내면 못 막음 → 한계
- **검증 계획:** 단위 테스트(통과·차단 각 경우, 0031 이하 그대로), 재채점, `pnpm check`

## 계획과 달라진 점
- 이 태스크 prd에 새 규칙을 돌리자, 판별 낱말을 나열한 내 가정 줄이 업무 값으로 잡혔다(규칙을 설명하는 글도 잡히는 오탐). 탈출 표시를 두지 않기로 했으므로 낱말 목록을 sdd로 옮기고 prd는 참조만 남겼다.
- `(확인됨: )`처럼 답이 빈 줄이 업무 값이 아니면 통과하던 구멍 → "답이 비었습니다"로 막음.
- 괄호 없는 "— 확인 필요"는 표시로 인정되면서 멈춤을 피해 감 → 괄호 없이도 남은 질문으로 봄.

**한계**
- 재채점은 "그때 이 규칙이 있었다면 멈췄을 것"까지다. 멈춤이 생기면 모델이 업무 값 낱말을 피해 쓰거나 칸에서 빼 몰래 지어냄으로 옮겨 갈 수 있다 → 새 실행 측정은 후속
- 몰래 지어냄 40%(17/42, 가장 큰 것은 M1 "결제 금액" 기준)는 이 규칙으로 줄지 않는다
- `(확인됨: …)`이 실제 사람 답인지 보지 않는다
