# 0024 — 모호한 요청에 AI는 되묻는가, 지어내는가 — PRD

- **이슈:** #28
- **문제:** 0016 실험의 실패는 결국 빈칸을 지어낸 것이었다(요약만 받은 설계 AI가 규칙·함수 모양을 스스로 정함). 그렇다면 **요청 자체가 애매할 때** AI는 되묻는가, 가정을 밝히는가, 몰래 지어내는가? 아직 잰 적이 없다.
- **목표:**
  1. 애매한 곳을 일부러 심은 과제와, 그 목록(정답지)을 만든다. 애매하지 않은 부분도 구분해 "과잉 질문"도 센다.
  2. 조건 3가지(혼자 / 혼자 + 되묻기 지시 / 역할 분리 + 원문 고정)를 각 3회 실행한다.
  3. 애매한 곳마다 되물음·가정 명시·몰래 지어냄을 판정하고 비교한다.
- **비목표:** 답을 받고 이어 가는 대화형 흐름(이번 실행 방식으로는 불가), 되묻기를 강제하는 장치 만들기(결과를 보고 다음 작업에서).

- [ ] 판정 기준: 되물음·가정 명시·몰래 지어냄 정의, 판정 방법(채점 AI + 표본 직접 확인)
