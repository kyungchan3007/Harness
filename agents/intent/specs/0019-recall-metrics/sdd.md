# 0019 — 복기 참조·체크박스 측정 도구 + 기준선 — SDD

요구사항: [prd.md](prd.md)

## 설계
- **읽은 문서:** 0017 `usage.mjs`(transcript 경로·중복 제거), transcript 실물의 user 줄 형태, ClauseLens 이슈 본문 형식
- **접근:**
  - `agents/harness/metrics/lib.mjs`(순수 함수) + `metrics.mjs`(파일·gh 입출력, 보고서). 경로 규칙은 0017 `projectTranscriptDir`·`listJsonl` 재사용.
  - **진짜 사용자 요청:** `type=user`이고 content가 문자열이며 `isMeta`가 아니고 사이드체인이 아닌 줄. 도구 결과(`tool_result`)·요청 중단 표시·이미지 메타는 제외.
  - **작업 시작 단위:** 요청을 시간순으로 보며, (서울 기준) 날짜가 바뀌었거나 `gitBranch`가 바뀐 첫 요청에서 새 단위를 시작. 단위 안에서 **첫 수정 도구(Edit·Write·MultiEdit·NotebookEdit) 전까지**를 "맥락 파악 구간"으로 본다.
  - **과거 기록 분류:** 맥락 파악 구간의 도구 호출 입력을 보고 분류. `JOURNAL|LEARNINGS|TASKS.md` → 작업 기록, `/specs/`·`prd|sdd|trace` → 태스크 문서, `memory/` → 메모리, `git log|git show|gh issue view|gh pr view` → git·이슈, `notion-fetch|notion-search` → Notion.
  - **중복 제거:** tool_use는 `id`로 한 번만 센다(스트리밍 중복).
  - **체크박스:** `- [x]`·`- [ ]` 줄 파싱. 미체크 줄에 사유 표지(`후속|다음|이후|보류|제외|대체|범위 밖|비목표|사유|별도|#숫자|→`)가 있으면 "사유 있음", 없으면 "방치".
  - **수동 지시:** 사용자 요청 중 `체크(해|박스|표시)|check ?box` 매칭 건수(원문은 남기지 않음).
  - **`[보완]` 반영:** `git log`에서 커밋별 `[보완]` 항목을 뽑고, 이후 커밋 메시지·TASKS.md에 그 항목의 핵심어(2글자 이상 명사형 토큰 상위 2개)가 함께 나오면 "언급 후보". 확정은 사람.
- **대안·트레이드오프:**
  - 세션 단위 측정: 한 세션이 한 달 넘게 이어지면(ClauseLens 8/17 세션, 도구 호출 3,105회) 시작이 한 번뿐이라 의미 없음. → 날짜·브랜치 단위.
  - "첫 N회 호출" 구간: 작업마다 탐색 길이가 달라 기준이 흔들림. → 첫 수정 전까지.
  - 반영률을 LLM으로 판정: 정확하지만 비용·비결정성. → 키워드 후보 + 사람 확인.
  - 사유 판정을 수동으로: 정확하지만 35개 이슈를 매번 볼 수 없음. → 사유 표지 정규식, 오판 가능성을 한계로 명시.
- **파일 계획:** `agents/harness/metrics/{lib,metrics,lib.test}.mjs`, `package.json`(`metrics`), 기준선 결과 `specs/0019-recall-metrics/baseline-clauselens.md`
- **위험:**
  - 원문 유출(public repo) → 보고서에는 수치·날짜·브랜치·이슈 번호만.
  - 정규식 분류 오판(과거 기록인데 못 잡거나, 현재 작업 파일을 과거 기록으로 셈) → 분류 규칙을 보고서에 함께 출력하고 한계로 기록.
  - ClauseLens의 다른 폴더(워크트리 등) 세션은 다른 transcript 폴더에 있어 누락될 수 있음 → 측정 범위(폴더·기간)를 보고서에 명시.
- **검증 계획:** 합성 transcript(중복·도구결과·메타·사이드체인·날짜/브랜치 전환)와 합성 이슈 본문으로 단위 테스트, 실제 ClauseLens 기록으로 기준선 실행 후 표본 몇 건을 원본과 대조, `pnpm check`

## 계획과 달라진 점
- **Bash 읽기·쓰기 구분 추가:** 경로만 보면 `echo … >> TASKS.md`(쓰기)도 "과거 기록 읽음"으로 세고, `cat > 파일`(쓰기)은 첫 수정으로 안 잡혔다 → 읽기 명령일 때만 읽음, 쓰는 명령은 수정으로.
- **"쓰려고 읽음" 제외 추가:** 원본 대조 표본(2026-09-14 `chore/expo-version-align`)에서 JOURNAL을 읽은 직후 JOURNAL을 수정 — 복기가 아니라 기록하려고 읽은 것. 같은 단위에서 나중에 수정하는 파일·Notion 페이지를 읽은 건 제외 → 참조율 42% → **33%** (21회 제외).
- **`--until` 추가:** 2026-09-29부터는 이 하네스 작업 세션이 ClauseLens 문서를 복사하려고 읽은 기록이라 복기와 무관 → 기준선은 그 전까지.
