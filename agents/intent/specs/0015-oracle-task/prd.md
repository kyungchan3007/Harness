# 0015 — 역할 분리 실험 과제(쿠폰) + 숨겨진 채점용 테스트 — PRD

- **이슈:** #18
- **문제:** 0016에서 1인 에이전트(A)와 역할 분리(B)를 비교하려면 **에이전트가 볼 수 없고, 그 자체가 맞다고 확인된 채점 기준**이 먼저 있어야 한다. 에이전트가 쓴 테스트로 채점하면 자기 착각을 공유하고, 채점 기준이 틀리면 실험 결과 전체가 무의미하다. 또 0014에서 준비 커밋 메시지가 검사자에게 정답 힌트로 새어 나간 일이 있었다.
- **목표:**
  1. **과제 문장** — A·B에 똑같이 주는 쿠폰 요구사항. 규칙마다 번호를 붙이고 함수 모양(타입·이름)을 고정해 "틀림"과 "다르게 해석함"을 구분할 수 있게 한다.
  2. **숨겨진 채점용 테스트(oracle)** — 함정별 약 20개. 테스트마다 근거 규칙 번호를 단다.
  3. **채점 기준 자체 검증** — 정답 구현은 전부 통과, 함정별로 일부러 틀린 구현은 해당 테스트에서 실패.
  4. **복사본 준비** — 이력 없는 중립 커밋 하나, 채점 기준·정답·실험 문서 제외, 누출 검사.
  5. **채점** — 복사본에 채점용 테스트를 넣어 돌리고 함정별 결과를 남긴 뒤 다시 뺀다.
- **비목표:** 에이전트 실행과 A·B 비교(0016), 과제 문장이 모호할 때의 행동(0003).
