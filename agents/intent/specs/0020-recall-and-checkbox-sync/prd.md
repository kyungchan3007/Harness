# 0020 — 복기 주입 + 체크박스 한 곳 관리·동기화 — PRD

- **이슈:** #12
- **문제:** 0019 기준선(ClauseLens) — 새 작업에서 첫 코드 수정 전에 과거 기록을 읽은 비율 33%, 작업 일지는 66개 중 1개, 이슈 체크박스 61% 방치. 0021에서는 `Closes #10`이 이슈를 자동으로 닫지 않았다. 기록을 **남기는 것**과 **다음 작업이 보는 것**, **체크하는 것** 사이에 연결 장치가 없다.
- **목표:**
  1. **복기 주입** — 대화 시작, 그리고 **날짜·브랜치가 바뀐 첫 요청**에서 미처리 `[보완]`·최근 작업 일지·현재 작업 상태를 AI 컨텍스트에 자동으로 넣는다.
  2. **체크박스 한 곳 관리** — 원본은 `prd.md` Acceptance. `pnpm issue-sync`로 이슈를 맞추고, `--check`로 어긋남을 찾는다.
  3. **방치 차단** — TASKS에서 done인 작업은 prd에 사유 없는 미체크가 있으면 완료 검사 실패.
  4. **머지 후 확인** — `pnpm issue-sync --close`: 브랜치가 main에 합쳐졌는데 이슈가 열려 있으면 닫는다.
- **비목표:** Notion 복기 읽기(hooks는 Notion을 못 읽음 — 복기 원본은 저장소의 커밋 `[보완]`·JOURNAL), ClauseLens 적용, 체크 항목별 근거(테스트 이름) 연결.
