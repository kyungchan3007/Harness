# 0023 — 채점표 세 번째 입력값 테스트 + 지난 실행 재채점 — PRD

- **이슈:** #26
- **문제:** 0016 B′-3에서 검사자가 잡은 유일한 결함(세 번째 입력값 `shippingPolicy`를 옵션 객체로 바꿈)을 숨겨진 채점표(0015, 21개)는 통과시킨다. 채점표가 과제 문장의 한 규칙("정책을 주면 그 정책, 안 주면 기본 정책")을 채점하지 않기 때문이다. 채점 기준에 빈틈이 있으면 "검사자가 잡은 결함"과 "놓친 결함"을 제대로 셀 수 없다.
- **목표:**
  1. 세 번째 입력값 규칙을 채점하는 테스트 추가(근거 문장 표시).
  2. 그 테스트가 실제로 잡는지 틀린 답안으로 자체 검증.
  3. 실행 테스트로는 못 잡는 위반(타입만 다름)을 확인·기록.
  4. 지난 12번 실행의 최종 코드를 재채점해 결론이 바뀌는지 확인 — 원래 21개 기준 결과는 그대로 둔다.
- **비목표:** 실험 재실행, 채점 기준의 다른 빈틈 전수 조사.

## Acceptance

- [x] 틀린 답안 추가: 정책 무시·입력 모양 변경(옵션 객체) → 새 테스트에서 떨어짐, 자체 검증 통과
- [x] 타입만 다른 위반(`Won` 대신 `number`)은 실행 테스트로 잡을 수 없음을 확인하고 기록
- [x] 지난 12번(A·B·B′·BR) 최종 코드 재채점, 결과표와 결론 변화 기록
