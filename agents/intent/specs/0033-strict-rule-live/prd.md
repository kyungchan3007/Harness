# 0033 — 업무 값 확인 규칙으로 새로 실행 — PRD

- **이슈:** #48
- **문제:** 0032 규칙(업무 값 `(가정)` 금지, `확인 필요`가 남으면 코드 수정 차단)의 효과는 기존 기록 다시 채점으로만 봤다. 실제로 막혔을 때 AI가 묻는지, 낱말을 피해 쓰는지, 칸에서 빼고 몰래 정하는지는 모른다.
- **목표:**
  1. 실험 복사본이 0032 규칙을 갖게 한다 (복사본 안 작업 번호를 규칙 적용 번호 이상으로).
  2. 복사본에 들어가는 0032 문서·테스트의 실험 힌트를 없앤다.
  3. Haiku 3회를 "모호하면 물어라" 지시 없이 실행하고, 멈추면 요청자 AI가 답해 이어 가게 한다.
  4. 0025 AM(필수 칸만)·0027 QI(지시로 묻기)와 멈춤·질문·낱말 피하기·몰래 지어냄·숨겨진 테스트 점수·비용을 비교한다.
- **비목표:** Sonnet·Opus 실행, ClauseLens 이식.

## 애매한 곳·가정
- 모델·횟수 — Haiku 4.5 3회 (가정: 0025 AM·0027 QI와 같은 조건이라 바로 비교 가능, 가장 지어내기 쉬운 모델)
- 지시 문장 — 0025 AM과 같은 문장, "모호하면 물어라" 없음 (가정: 장치만으로 묻게 되는지가 질문)
- 정답 의도 — 흔한 의도(intent.json) (가정: 0027 QI·0025 AM 채점과 같은 기준)
- 문답 횟수 — 최대 3번 (가정: 0027은 2번이었지만 막힘이 여러 번 날 수 있음)
