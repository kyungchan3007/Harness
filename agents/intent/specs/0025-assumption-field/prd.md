# 0025 — "애매한 곳·가정" 칸을 장치로 강제하면 가정이 남는가 — PRD

- **이슈:** #30
- **문제:** 0024에서 애매한 요청을 받은 AI는 평소 95%, 역할 분리 + 원문 고정에서도 86%를 몰래 지어냈다. 설계자 지시에 "원문에 없음 — 설계 결정 표시"가 있었지만 3번 중 1번만 따랐다. 지시가 아니라 **필수 칸(장치)** 이면 남는가?
- **목표:**
  1. prd에 `## 애매한 곳·가정` 칸을 필수로 만든다 (0025 이후 태스크). 줄마다 `(가정)`·`(확인 필요)` 표시, 정말 없으면 `없음 — 이유`.
  2. 0024와 같은 과제·같은 지시로 장치만 더해 다시 실행한다 (AM·BM 각 3회).
  3. 0024 판정 장치로 판정해 A·BR과 비교한다.
- **비목표:** 큰 모델 재실행, 묻고 → 답 받고 → 이어 가기 (별도 이슈). 칸의 내용 품질(가정이 맞는지) 판정.

## 애매한 곳·가정
- 장치의 범위 — 0025 이후 태스크만 검사, 이전 기록은 면제 (가정: 지난 기록을 고치면 기록의 의미가 바뀜)
- 칸의 위치 — prd (가정: 요구를 고정하는 문서가 prd이고, 설계자가 처음 쓰는 문서)
- 비교 기준 — 0024 A·BR 결과를 그대로 씀, 다시 돌리지 않음 (가정: 같은 모델·과제·지시라 재사용 가능. 저장소 상태 차이는 한계에 적음)
