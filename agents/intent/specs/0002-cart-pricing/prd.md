# 0002 — 도메인 전환: 장바구니 금액 계산 — PRD

## PRD
- **문제:** 메모 CRUD는 규칙이 너무 단순해서 에이전트가 틀릴 일이 없다. 그러면 게이트·가드레일이 실제로 실수를 막는지 관찰할 수 없다.
- **목표:** 쇼핑몰 할인·주문 엔진의 첫 단계로 장바구니와 금액 계산(상품 합계·배송비·결제 금액)을 만든다. 규칙은 [domain.md](../../context/domain.md)가 단일 소스다.
- **비목표:** 쿠폰(0003), 주문 상태(0005), 영속화, HTTP API.

## Acceptance
- [x] 메모 도메인 코드와 테스트가 제거되었다
- [x] 장바구니가 domain.md의 장바구니 규칙 1~5를 지킨다 (규칙마다 테스트 1개 이상)
- [x] 금액 계산이 domain.md의 배송비 규칙 1~3을 지킨다 (경계값 49,999 / 50,000 포함)
- [x] 금액 계산이 순수 함수이고, 할인 금액을 인자로 받을 수 있다 (0003 대비)
- [x] `pnpm check` ALL PASS
