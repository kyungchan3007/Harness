# 0016 — 역할 분리 실험 실행·비교·결론 — PRD

- **이슈:** #21
- **문제:** 0013~0015로 역할 분리 장치(권한·판정 흐름)와 채점 기준을 만들었지만, **역할을 나누면 실제로 결함을 더 잡는지**는 아직 재 본 적이 없다. 0014의 성공 1회는 힌트 누출이 섞여 있었다.
- **목표:**
  1. 실행 스크립트 — 복사본 준비 → AI 실행 → 숨겨진 채점 → 지표 수집을 한 번에.
  2. A(1인)·B(역할 분리)·B′(역할 분리 + 원문 공유, 시범 결과로 추가) 각 3회, 같은 과제·모델·시작 상태.
  3. 정확도·잡은/놓친 결함·비용·역할 우회·권한 밖 시도·누출 접근을 결과표로.
  4. 결론과 한계를 기록.
- **비목표:** 모델별 분리(Claude↔Codex), 모듈 소유권 분리, 통계적으로 유의한 결론(3회로는 불가 — 경향만).
