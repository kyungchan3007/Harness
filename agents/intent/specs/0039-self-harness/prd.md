# 0039 — Self-Harness 축소판: 실패 기록으로 하네스를 스스로 고치는 루프 — PRD

- **이슈:** #62
- **문제:** harness-lab은 규칙을 사람이 판단해 추가해 왔다. 2026 연구(Self-Harness · AHE)는 실패 기록에서 규칙을 자동 제안하고 평가 게이트로 걸러 반영한다. 이 방식이 사람 규칙만큼 좋은지, 정답에 맞춘 과적합 규칙을 만드는지 모른다. 또 0038은 원문 위치를 짚어 줘 실패가 거의 없어 고칠 대상이 없었다.
- **목표:** 원문 위치를 알려 주지 않는 0038 변형에서 H0(최소)·H-human(사람)·H-auto(자동 개선 k회)를 비교하고, 자동 규칙이 평가 전용 규칙에도 통하는지(일반화) 본다.
- **비목표:** Dayro 적용, 모델 학습, 프롬프트 자동 최적화 도구 도입
