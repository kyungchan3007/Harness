# 0014 — 검사자 판정 흐름 — PRD

- **이슈:** #16
- **문제:** 0013에서 역할별 권한(설계자·구현자·검사자)을 강제했지만, **검사자가 어떻게 판정하고 반려되면 어떻게 되돌아가는지**가 정해지지 않았다. 판정 형식이 없으면 근거 없는 반려나 느슨한 통과를 구분할 수 없고, 반려가 끝없이 반복될 수 있다.
- **목표:**
  1. 판정서(`verdict.md`) 형식 — 회차마다 판정(approved/rejected)과 근거. 반려는 "어느 완료 조건·규칙을, 어떤 입력에서, 기대값과 실제값"을, 통과는 "확인한 것"을 적어야 유효.
  2. `pnpm verdict` — 판정서를 읽고 다음 차례(검사자 / 구현자 / 완료 / 막힘)를 알려준다.
  3. **반려 최대 2회** — 세 번째도 반려면 막힘(blocked). 사람이 판단한다.
  4. 완료 검사 — 역할 분리로 진행한 작업(prd에 `- **역할 분리:** on`)이 done이면 최신 판정이 approved여야 통과.
- **비목표:** 실험 과제·채점(0015), 실험 실행·비교(0016), 조율자 우회 측정.

- [x] `pnpm verdict`: 다음 차례(검사자·구현자·완료·막힘)와 반려 횟수 표시
