# 0013 — 역할 식별 확인 + 역할별 권한 강제 — PRD

- **이슈:** #14
- **문제:** 역할 분리 실험(0012 설계)을 하려면 설계자·구현자·검사자가 **자기 권한 밖 파일을 고치지 못해야** 한다. 역할을 말(프롬프트)로만 주면 경계를 넘어도 막을 수 없다(0009 교훈). 그런데 자동 검사(hook)가 "지금 어느 역할이 고치는지"를 알 수 있는지(`agent_type`)는 **문서로만 확인했고 실제로는 확인하지 않았다.**
- **목표:**
  1. 실제 실행으로 `agent_type`이 hook 입력에 들어오는 조건을 확인한다.
  2. 역할 3개를 Claude Code 보조 에이전트(`.claude/agents/*.md`)로 정의한다.
  3. guard가 역할별 허용 경로 밖 수정을 막는다. 역할 없는 메인 대화는 기존 규칙 그대로.
  4. 자동 기록에 역할을 남긴다(0016 비교용).
- **비목표:** 검사자 판정 흐름(0014), 실험 과제·채점(0015), 실험 실행(0016).

| 역할 | 고칠 수 있음 | 고칠 수 없음 |
| --- | --- | --- |
| 🎯 designer (설계자) | `agents/intent/**`(prd·sdd·trace), `agents/context/**`, `agents/orchestration/TASKS.md` | 코드(`src/**`) · 판정서 |
| 🔨 builder (구현자) | `src/**`, 과정 기록 `trace.md` | prd·sdd·판정서·규칙 문서 |
| 🔍 verifier (검사자) | 판정서 `verdict.md`, 과정 기록 `trace.md` | 코드·prd·sdd·규칙 문서 |
