## 설계
- **읽은 문서:** 0019 sdd(측정 도구·기준선), `agents/harness/metrics/{lib,metrics}.mjs`, ClauseLens transcript 3개의 실제 오탐 22건(메타 필드와 일치 주변 글자)
- **접근:**
  1. `toEvents`: `isCompactSummary` 제외, 같은 `uuid` 요청은 한 번만, 요청 글은 `typedText`로 직접 친 부분만
  2. `typedText`: `<bash-input|bash-stdout|bash-stderr|system-reminder|pasted_content|local-command-*|command-*|task-notification>…</…>`와 `<…/>` 자체 닫힘 태그 제거
  3. `CHECK_REQUEST`: "체크 … 해줘/해야/채워/안 해/확인 안/확인 해줘", "왜/안 … 확인 안 해 … 체크" 등 요청형만
  4. `followupSection(gitDir, since, until)`: 커밋 시각(`%cI`)으로 기간 안 커밋의 `[보완]`만 세고, 언급 여부는 그 뒤 전체 커밋+TASKS에서
  5. `inPeriod`: 시간대 없는 시각은 UTC
- **대안·트레이드오프:**
  - 메타 필드(`origin.kind === "human"`)로만 거르기: `<bash-input>`도 human으로 기록돼 못 거름 → 태그 제거와 함께
  - 넓은 규칙 유지 + 붙여 넣은 목록만 제외: 태그 없이 붙여 넣은 글을 기계로 구분할 수 없음 → 요청형으로 좁힘(놓치는 요청이 생길 수 있음, 한계에 적음)
- **파일 계획:** `agents/harness/metrics/{lib.mjs, metrics.mjs, lib.test.mjs}`
- **위험:** 요청형 규칙이 실제 요청을 놓침 → 실제 3건(9/22×2, 10/2)이 모두 잡히는지 단위 테스트, 재측정으로 손 확인 값과 대조
- **검증 계획:** 단위 테스트(참 3·오탐 5·기간), ClauseLens 세 구간 재측정, `pnpm check`
