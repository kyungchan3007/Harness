# 0027 — 묻고 → 답 받고 → 이어 가면 결과가 좋아지는가 (대화형) — PRD

- **이슈:** #32
- **문제:** 0024에서 "모호하면 물어보라" 지시(Q)를 받은 AI는 질문 5~6개를 하고 멈췄다. 하지만 `claude -p` 한 번 실행이라 답을 받고 이어 가는 것은 못 봤다. 묻는 것이 **결과를 실제로 좋게 하는지** 모른다.
- **목표:**
  1. 요청자의 진짜 의도(애매한 곳 M1~M7마다 답 하나)와, 그 의도대로 쓴 숨겨진 테스트를 만든다.
  2. 대화형 실행(QI): Q 지시로 시작 → 질문이 나오면 요청자 AI가 **물어본 것만** 답 → 같은 세션을 이어서 구현 (최대 2번 문답).
  3. QI와 지난 실행(0024 A·BR)을 같은 숨겨진 테스트로 채점해 비교한다.
- **비목표:** 큰 모델(#31), 필수 칸 장치(#30), 사람이 직접 답하는 실행.
