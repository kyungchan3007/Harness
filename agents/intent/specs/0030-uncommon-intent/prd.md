# 0030 — 흔하지 않은 정답 의도로 다시 — 묻는 것의 진짜 가치 — PRD

- **이슈:** #41
- **문제:** 0027·0028의 정답 의도(배송비 제외·내림·쿠폰 절반·VIP 2배·곱셈)가 가장 흔한 추측과 겹쳐, 추측만으로도 높은 점수가 나왔다(Sonnet 혼자 4/5). 대화형 100%가 "물어서" 맞춘 건지 "쉬운 의도" 덕인지 구분이 안 된다.
- **목표:**
  1. 흔하지 않은 정답 의도 + 숨겨진 테스트를 만들고, 틀린 구현으로 함정을 확인한다.
  2. 혼자 정한 지난 구현(질문·답 없음)은 새 테스트로 재채점한다 — 의도가 바뀌어도 구현은 같다.
  3. 대화형은 새 의도로 다시 실행한다(Haiku 3회·Opus 3회).
  4. 흔한 의도 vs 흔하지 않은 의도 점수를 비교한다.
- **비목표:** 구현이 큰 과제의 조합 손익분기, 검사자 모델 비교.

## 애매한 곳·가정
- 흔하지 않은 값 선택 — 할인 전 합계·반올림·쿠폰 0·VIP 3배·VIP는 쿠폰 예외 (가정: 각각 실제 서비스에 있을 법하지만 추측으로는 잘 안 고를 값)
- 혼자 정함 재사용 — 다시 돌리지 않음 (가정: 질문·답이 없으면 의도가 결과에 영향을 못 줌)
- 연결 파일 재사용 — 0027에서 만든 것 그대로 (가정: 값 전달만 하므로 의도와 무관)
