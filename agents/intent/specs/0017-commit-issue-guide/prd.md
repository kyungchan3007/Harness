# 0017 — 커밋·이슈 지침서 (허점·보완점·컨텍스트·토큰) — PRD

- **문제:**
  - 작업하면서 드러난 **엔지니어링 허점**과 **보완할 점**이 trace·LEARNINGS에 흩어져, 커밋·이슈만 봐서는 보이지 않는다.
  - 작업 한 번에 **컨텍스트를 얼마나 쓰고 토큰을 얼마나 소비했는지** 아무 데도 남지 않는다. 하네스 실험(예: 역할 분리 비용)을 비교하려면 이 수치가 필요하다.
  - 규칙을 문서로만 두면 건너뛴다(0009 교훈).
- **목표:**
  - 모든 태스크 커밋·이슈·PR에 `[허점]` `[보완]` `[컨텍스트·토큰]` 세 섹션을 남기는 **지침서**를 만든다.
  - 토큰·컨텍스트 수치는 사람이 추정하지 않고 **Claude Code 대화 기록(transcript)에서 자동 집계**한다.
  - 커밋 시 **git hook이 섹션을 검사**하고, 토큰 섹션은 비어 있으면 **자동으로 채운다**.
  - 이슈·PR 템플릿에도 같은 섹션을 둔다.
- **비목표:** Codex 토큰 집계(형식이 다름, 후속), 비용(달러) 환산, CI에서 커밋 메시지 검사.
