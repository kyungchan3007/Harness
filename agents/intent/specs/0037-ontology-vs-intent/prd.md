# 0037 — 온톨로지를 더하면 좋아지는가 — PRD

- **이슈:** #58
- **문제:** harness-lab은 지금까지 intent(원문·prd·sdd)만으로 AI를 몰았고 실제로 동작했다. 개념·관계·불변식을 정리한 온톨로지를 더하면 결과가 더 좋아지는지는 재 본 적이 없다.
- **목표:** 개념이 많은 새 과제에서 세 조건을 같은 방식으로 돌려 비교한다.
  - A · intent만 (`agents/context/domain.md`도 뺀다)
  - B · A + 문서형 온톨로지 (사람이 읽는 개념·관계·불변식·용어 문서)
  - C · A + 기계 판독형 온톨로지 (YAML/JSON 정의 + 어긋나면 막는 자동 검사)
  - 지표: 숨겨진 테스트 정답률 · 몰래 지어냄·질문 수 · 비용·시간
- **비목표:** ClauseLens 적용, 온톨로지 자동 생성, 모델 간 비교
