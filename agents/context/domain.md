# Domain — 쇼핑몰 할인·주문 엔진

이 문서가 도메인 규칙의 단일 소스입니다. 코드와 이 문서가 다르면 문서를 기준으로 코드를 고치거나, spec을 거쳐 문서를 먼저 고칩니다.

## 용어

| 용어 | 뜻 |
| --- | --- |
| 원(Won) | 모든 금액의 단위. **항상 0 이상의 정수**. 소수점 금액은 존재하지 않는다 |
| 상품 줄(LineItem) | 장바구니의 한 줄. `sku`, `name`, `unitPrice`, `quantity` |
| 상품 합계(subtotal) | 모든 줄의 `unitPrice × quantity` 합 |
| 할인(discount) | 상품 합계에서 빼는 금액. 0002에서는 항상 0 (쿠폰은 0003) |
| 배송비(shipping) | 할인 후 금액 기준으로 정해지는 고정 금액 |
| 결제 금액(total) | `subtotal − discount + shipping` |

## 장바구니 규칙 (0002)

1. `unitPrice`는 0 이상의 정수다.
2. `quantity`는 1 이상 99 이하의 정수다.
3. 같은 `sku`를 다시 담으면 새 줄을 만들지 않고 수량을 더한다. 합친 수량이 99를 넘으면 거부한다(기존 수량은 유지).
4. 수량을 0으로 바꾸는 것은 허용하지 않는다. 빼려면 `remove`를 쓴다.
5. 없는 `sku`의 수량 변경은 거부하고, 없는 `sku`의 `remove`는 아무 일도 하지 않는다.

## 배송비 규칙 (0002)

1. 기본 배송비는 3,000원.
2. **할인 후 상품 금액**(`subtotal − discount`)이 50,000원 **이상**이면 무료.
3. 빈 장바구니는 배송비 0원, 결제 금액 0원.
