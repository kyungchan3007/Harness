# 0030 — 쿠폰 적용 기능 설계 — PRD

## PRD
- **이슈:** #1
- **문제:** 0002에서 장바구니 금액 계산을 만들었지만, 현실의 쇼핑몰은 쿠폰 할인을 지원해야 한다. 0030은 단일 쿠폰 결합 정책을 정의하고 구현한다.
- **목표:** 다양한 쿠폰 규칙(정률/정액, 상품/주문, 조건, 중복 제약)을 처리하는 `priceWithCoupons()` 함수를 만든다. 규칙은 [domain.md](../../context/domain.md) 쿠폰 규칙 1~12를 단일 소스로 한다.
- **비목표:** 쿠폰 검증(유효기간, 발급 여부 등), 쿠폰 생성/관리 API, 주문 처리.

## Acceptance
- [x] domain.md에 쿠폰 규칙 1~12가 정의되었다
- [x] 쿠폰 규칙 1~12 각각을 테스트로 검증했다 (규칙마다 테스트 1개 이상)
- [x] `priceWithCoupons(items, coupons, shippingPolicy?)` 함수가 구현되었고, 서명은 sdd.md와 일치한다
- [x] 상품 쿠폰과 주문 쿠폰이 올바른 순서로 적용된다
- [x] 정률 쿠폰과 정액 쿠폰의 계산이 domain.md 규칙을 따른다
- [x] `minOrder` 미충족 쿠폰은 오류 없이 할인 0원으로 처리된다
- [x] 정액 쿠폰의 할인이 기준금액(상품/주문별)을 초과하지 않는다
- [x] `maxDiscount`가 있으면 할인을 그 이상으로 올리지 않는다
