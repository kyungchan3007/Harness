# 0030 — 쿠폰 적용 — PRD

- **이슈:** #1

## 개요

장바구니에 쿠폰을 적용하여 최종 금액을 계산하는 기능을 제공합니다. 상품 쿠폰과 주문 쿠폰을 구분하여 처리합니다.

## 요구사항

### 쿠폰 타입

| 구분 | 설명 |
| --- | --- |
| 상품 쿠폰 | 특정 상품(sku)에만 적용되는 쿠폰. 상품당 1장까지만 사용 가능 |
| 주문 쿠폰 | 주문 전체에 적용되는 쿠폰. 최대 1장만 사용 가능 |

### 할인 방식

- **정률(rate)**: 기준 금액 × value / 100 (원 미만 버림)
- **정액(fixed)**: value원 (기준 금액을 초과할 수 없음)

### 적용 조건

1. **최소 주문 금액(minOrder)**: 할인 전 상품 합계가 이 값 이상일 때만 적용
   - 조건 미충족 시 오류 아닌 무적용(할인 0원)
2. **할인 상한(maxDiscount)**: 쿠폰의 할인 금액이 이 값을 초과할 수 없음

### 적용 순서

1. 상품 쿠폰을 모두 적용
2. 주문 쿠폰을 적용
3. 배송비 및 결제 금액 계산

### 규칙

- 상품 쿠폰의 기준 금액: `unitPrice × quantity` (줄 금액에 한 번)
- 주문 쿠폰의 기준 금액: `상품 합계 − 상품 쿠폰 할인 합계`
- 결과의 discount: 모든 쿠폰 할인의 합
- 배송비와 결제 금액: 모든 할인 후 금액 기준으로 계산
- 장바구니가 비어있으면 쿠폰 무시, 모든 금액 0 반환

### 검증

- 정률 쿠폰: value는 1~100의 정수
- 정액 쿠폰: value는 1 이상의 정수
- maxDiscount, minOrder: 0 이상의 정수
- 상품 쿠폰: sku 필수
- 상품 쿠폰: 장바구니에 없는 상품은 오류
- 중복 쿠폰: 상품당 1장, 주문 전체 1장 초과 시 오류
