- **규칙 10 위반: 배송비 계산 오류**
  - 입력: 상품 60,000원 + 10,000원 할인 쿠폰 → 할인 후 50,000원
  - 기대: shipping = 0 (50,000원 **이상**이면 무료, 규칙과 domain.md)
  - 실제: shipping = 3,000원
  - 원인: 75번 줄 `const s = after > shippingPolicy.freeThreshold` — 초과(`>`)를 사용하지만, 규칙은 **이상**(`>=`)이어야 함

- **규칙 3**: maxDiscount 상한 ✓ (500 → 300)
- **규칙 4**: minOrder 조건 불만족 시 할인 0 ✓ (오류 아님)
- **규칙 5**: 상품 쿠폰 줄 금액 기준 ✓ (unitPrice × quantity = 30,000 기준)
- **규칙 6**: 주문 쿠폰 기준 = subtotal - 상품할인 ✓ (90,000 기준, 9,000 할인)
- **규칙 7**: 적용 순서 (상품→주문) ✓
- **규칙 8**: 개수 제한 ✓ (상품당 1장, 주문 1장, 없는 상품)
- **규칙 9**: 입력 검증 ✓ (0%, 0원 등)
- **규칙 11**: 빈 장바구니 = 0 ✓
