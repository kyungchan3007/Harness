### 확인한 것

- API: 요청한 인터페이스·함수·오류 클래스의 이름과 타입 확인.
- 규칙 1: 상품·주문 정률 쿠폰의 소수 발생 입력에서 위반 확인. 정수 결과와 1%·100% 경계값은 통과.
- 규칙 2: 정액 할인과 기준 금액 초과 시 제한 확인.
- 규칙 3: 정률·정액의 할인 상한 및 상한 0원 확인.
- 규칙 4: 최소 주문 금액 미만·동일·초과, 할인 전 합계 사용, 조건 미달 쿠폰만 제외 확인.
- 규칙 5: 수량이 여러 개인 상품에서 줄 금액 기준으로 한 번 적용되는지 확인.
- 규칙 6: 모든 상품 할인 차감 후 주문 할인 계산 확인.
- 규칙 7: 쿠폰 목록을 뒤집어도 결과가 같은지 확인.
- 규칙 8: 상품·주문 쿠폰 중복과 없는 상품에 대해 `CouponError` 확인.
- 규칙 9: 범위 밖 값·소수·NaN·Infinity·sku 누락의 `CouponError`, 상한·최소 금액 0 허용 확인.
- 규칙 10: 할인 합산, 할인 후 무료 배송 경계 50,000원, 기본·사용자 지정 배송비 및 결제 금액 확인.
- 규칙 11: 빈 장바구니는 쿠폰에 접근하지 않고 모든 금액 0 반환 확인.
- 규칙 12: 배열과 내부 객체를 동결하고 호출 전후를 비교하여 입력 불변 확인.
