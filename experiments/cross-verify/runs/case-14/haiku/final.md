## 핵심 문제: 규칙 8 상품 쿠폰 중복 검사

코드 58번 줄을 다시 확인하면:

```ts
if (false) throw new CouponError(`상품 쿠폰은 상품당 1장입니다: ${sku}`);
```

`if (false)`이므로 항상 실행되지 않습니다. 같은 SKU에 여러 상품 쿠폰이 있어도 오류가 나지 않습니다. 조건문이 `if (seen.has(sku))`여야 합니다.
