## 판정: rejected

### 근거
- 규칙 9 · 입력: `{"scope":"order","type":"rate","value":100}` · 기대: 유효한 쿠폰으로 계산됨 · 실제: `CouponError: 정률 쿠폰 할인율은 1~100 정수여야 합니다: 100`

정률 쿠폰의 value 범위 검증이 규칙과 맞지 않습니다. 규칙 9는 "정률 `value`가 1~100의 정수가 아님"이라고 명시하므로 value 100은 유효해야 하는데, 코드의 20번 줄 조건 `value >= 1 && value < 100`은 1~99만 허용합니다.

### 확인한 것
- **규칙 1** (정률 할인·원 미만 버림): `Math.floor((base * coupon.value) / 100)` 사용 ✓
- **규칙 2** (정액 할인·기준 금액 초과 불가): `Math.min(coupon.value, base)` 사용 ✓
- **규칙 3** (maxDiscount 제한): 적용됨 ✓
- **규칙 4** (minOrder 조건): 미충족 시 할인 0원 반환 ✓
- **규칙 5** (상품 쿠폰 기준 금액): `unitPrice × quantity` 계산 ✓
- **규칙 6** (주문 쿠폰 기준 금액): `subtotal - itemDiscount` 계산 ✓
- **규칙 7** (적용 순서): 상품 쿠폰 → 주문 쿠폰 순서 ✓
- **규칙 8** (쿠폰 제한): 상품당 1장, 주문 1장, 없는 SKU 체크 ✓
- **규칙 9** (유효성): 
  - 정액 value ≥ 1: ✓
  - maxDiscount/minOrder ≥ 0: ✓
  - 상품 쿠폰에 sku 필수: ✓
  - **정률 value 범위: ✗ (1~99만 허용, 100 거부)**
- **규칙 10** (discount·배송비): 할인 후 금액 기준 배송비 계산 ✓
- **규칙 11** (빈 장바구니): 모든 금액 0 반환 ✓
- **규칙 12** (items·coupons 변경 안 함): 읽기 전용 매개변수 ✓
