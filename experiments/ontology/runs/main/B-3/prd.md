## 목표
메모리 기반 샌드박스 내에서 시료(액체) 관리 엔진을 구현한다.
- **시료 생명 주기:** 수용(receive) → 분취(split) → 예약(reserve) → 소비(consume) → 폐기(discard)
- **추적 대상:** 시료 양·상태, 용기 배정, 예약 상태, 보관 책임자, 이력
- **일관성:** 계보 관계 불변, 수량 보존, 원자성

## 공개 예제 (검증용)
- 시료·예약·분취·소비 등 8개 명령
- 각 명령의 성공·실패 케이스 (계보 검증, 멱등성, 원자성)

## 애매한 곳·가정
- 멱등성 키 생성: `${eventId}:${JSON.stringify(args)}` 사용 (객체 키 순서 무시는 JSON 표준에서 달성 불가, args 배열 순서는 구별함) — (가정)
- eventId 재사용: 실패한 명령의 eventId는 기록되지 않음 (재시도 가능) — (가정)
- 용기 배정: 한 번 배정되면 이동 전까지 같은 용기에 유지 — (가정)
- 계보 관계: 분취 후 부모-자식 관계는 불변 (자식은 인접 부모만 추적) — (가정)

## 주요 설계 결정
- **상태 머신:** 시료는 ACTIVE → DEPLETED|DISCARDED
- **에러 우선 검사:** 이전에 성공한 eventId 검사 (R7) → 일반 검증 → 상태 변경
- **복사:** 입력 객체 즉시 복사 (호출자의 나중 수정 방지)
- **예약 매커니즘:** remaining과 reserved를 분리하여 이용 가능량 계산
