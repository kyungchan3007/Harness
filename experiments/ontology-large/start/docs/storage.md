# 보관 정책 — 보관 등급

시료마다 요구 보관 등급(`storageGrade`), 용기마다 지원 등급 목록(`supportedGrades`)이 있습니다. 등급은 `AMBIENT`·`CHILLED`·`FROZEN` 세 가지입니다.

- **적합성은 지원 목록에 시료의 요구 등급이 정확히 들어 있는지로만 판단합니다.** 등급 사이에 대체·상하 관계는 없습니다 — `FROZEN`을 지원하는 용기라도 목록에 `CHILLED`가 없으면 `CHILLED` 시료를 넣을 수 없습니다.
- 적용 범위: 시료를 용기에 넣는 모든 경우 — 받기(`receive`), 분취 자식의 용기(`split`), 이동(`move`), **운송 목적지(`startTransit`)**. 맞지 않으면 `STORAGE_INCOMPATIBLE`.
- **시료의 요구 보관 등급은 만들어진 뒤 어떤 명령으로도 바뀌지 않습니다.**
- 분취 자식의 등급은 분취 구현에 적힌 규칙을 따릅니다(`src/lab/samples.ts`).
- 운송 목적지가 맞지 않아 운송 시작이 실패하면, 실패 규칙([engine.md](engine.md) E6)대로 운송 기록·목적 용기 확보·다른 상태 무엇도 생기거나 바뀌지 않습니다.
