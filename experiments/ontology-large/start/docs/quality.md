# 품질관리 — 격리

격리는 시료를 품질 확인이 끝날 때까지 쓰지 못하게 묶어 두는 것입니다. 시료의 생애 상태(`status`)와는 따로 `quarantined`로 표시합니다.

- `quarantine`·`release`는 ACTIVE 시료의 격리 여부만 설정합니다. 이미 같은 값이어도 성공합니다.
- 격리된 시료에는 분취·새 예약·예약 소비를 할 수 없습니다 → `QUARANTINED`.
- **격리와 해제는 이미 있는 예약을 건드리지 않습니다.** 예약의 상태·양·만료 시각은 그대로이며, 예약이 있어도 격리할 수 있습니다.
- **격리는 다음 명령을 막지 않습니다:** 예약 취소, 이동, 폐기, 책임자 변경, 운송 시작·도착·취소. 이 명령들의 다른 제한(예: 예약이 있으면 폐기 불가, 운송 중 이동 불가)은 그대로 적용됩니다.
- 격리 중에 예약을 취소하면 예약 양만 풀리고, 격리와 실제 남은 양은 그대로입니다(예약 쪽은 [reservations.md](reservations.md)).
