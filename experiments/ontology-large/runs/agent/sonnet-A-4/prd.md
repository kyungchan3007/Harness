- **이슈:** #1
- **문제:** `src/lab/`의 시료 보관 엔진에 새 공개 계약(`types.ts`)의 필드와 메서드가 연결돼 있지 않다. `quarantine`·`release`·`advanceTime`·운송 3종은 미구현이고, 보관 등급 검사와 예약 만료 검증, 분취 자식의 등급 상속이 빠져 있다.

- 운송 목적 용기 확보 — 시료가 출발 용기를 점유한 채 목적 용기도 점유 표시 (가정: storage.ts 정책 주석의 "배타적 확보"를 점유 표로 구현)
- 만료 시각·진행 시각 검증 — 0 이상 MAX_SAFE_INTEGER 이하 정수 (가정: types.ts의 Tick 정의 그대로)
- 격리 중 예약 취소·운송 등은 막지 않음 — (가정: quality.md 그대로)
- 여러 규칙을 어길 때의 오류 코드 — 아무 것이나 허용 (engine.md E6-4), 문서 순서로 검사 (가정)
