# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문해도 고객에게 돌아가는 보상이 없다. 결제 금액에 비례한 포인트를 적립해 재구매를 유도하고 싶다.
- **목표:** 주문 1건의 적립 포인트를 계산하는 순수 함수를 `src/pricing/points.ts`에 만든다. 규칙은 [domain.md](../../context/domain.md) "포인트 적립 규칙 (0030)"이 단일 소스다.
- **비목표:** 포인트 잔액 저장·영속화, 포인트 사용(결제 차감), 주문 취소·환불 시 회수, 만료, 적립 상한.

## 요청 원문
- 결제 금액의 1%를 포인트로 적립합니다.
- 쿠폰을 쓴 주문은 적립을 좀 줄여 주세요.
- VIP 회원은 더 많이 적립해 주세요.
- 포인트는 1포인트 단위(정수)입니다.
- 코드는 `src/pricing/points.ts`에 만들어 주세요.

## 질문과 답 (2026-10-07 요청자 답변)
| # | 질문 | 답 |
| --- | --- | --- |
| 1 | 적립 기준 금액 | `subtotal − discount` (배송비 제외) |
| 2 | 쿠폰 감액 폭 | 적립률 절반 (1% → 0.5%) |
| 3 | 쿠폰 사용 판정 | `PriceBreakdown.discount > 0`. 입력은 `PriceBreakdown` + `{ grade }` |
| 4 | VIP 적립률 | 2배 (1% → 2%). 등급은 `"VIP" \| "NORMAL"` |
| 5 | VIP + 쿠폰 | 2배 먼저, 그다음 절반 (2% → 1%) |
| 6 | 정수 처리 | 내림 |
| 7 | 범위·상한·0원 | 요청자가 위임 → 에이전트 결정: 계산 함수만, 상한·최소 금액 없음, 0원이면 0포인트, 잘못된 입력(음수·소수·할인 > 합계)은 `RangeError` |
