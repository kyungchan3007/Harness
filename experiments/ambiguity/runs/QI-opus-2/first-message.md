**만든 것**

  - `prd.md`: 요청 원문, 아래 질문 7개, 완료 조건 초안이 들어 있습니다.

## 답이 필요한 질문

1. **적립 기준 금액:** 이 저장소의 규칙 문서(`domain.md`)는 "결제 금액"을 `상품 합계 − 할인 + 배송비`로 정의합니다. 배송비를 포함한 이 금액으로 적립하나요, 배송비를 뺀 `상품 합계 − 할인`으로 적립하나요?
2. **쿠폰을 쓰면 얼마나 줄이나요?** 예를 들어:
   - 적립률을 0.5%로 내림
   - 적립 포인트를 절반으로 줄임
   - 따로 줄이지 않음(쿠폰 할인이 이미 결제 금액에서 빠져 있으므로)
3. **"쿠폰을 쓴 주문"은 어떻게 구분하나요?** 쿠폰 기능은 아직 코드에 없습니다. 할인이 1원 이상이면 쿠폰 주문으로 보나요, 아니면 쿠폰 사용 여부를 따로 입력받나요? 할인 금액이 없는 쿠폰(예: 무료배송 쿠폰)도 적립을 줄이나요?
4. **VIP는 얼마나 더 적립하나요?** 예: 2%, 1%p 추가, 2배. 회원 등급은 일반과 VIP 두 가지뿐인가요?
5. **VIP 회원이 쿠폰을 쓰면 어떻게 계산하나요?** 예: VIP 적립률에 쿠폰 감액을 그대로 적용 / 쿠폰을 쓰면 VIP 혜택 없음.
6. **1포인트 미만은 어떻게 처리하나요?** 버림, 반올림, 올림 중 어느 것인가요? 계산 단계마다 정수로 맞추나요, 마지막에 한 번만 맞추나요?
7. **이번 작업 범위는 어디까지인가요?**
   - 적립 포인트를 계산하는 함수까지만 만드나요, 잔액 저장과 주문 취소 시 회수까지 하나요?
   - 적립 상한이나 최소 주문 금액이 있나요?
   - 결제 금액이 0원인 주문은 0포인트로 보면 되나요?

답을 주시면 순서대로 진행하겠습니다.
1. `domain.md`에 "포인트 적립 규칙 (0030)" 절을 추가합니다.
2. `prd.md`의 완료 조건을 확정합니다.
3. `src/pricing/points.ts`와 테스트를 만듭니다. 테스트는 일반/VIP와 쿠폰 사용/미사용 4가지 조합과 소수점 처리 경계값을 다룹니다.
4. `pnpm check`가 통과하면 기록을 남깁니다.

질문마다 예시로 든 값 중 하나를 고르셔도 됩니다.
