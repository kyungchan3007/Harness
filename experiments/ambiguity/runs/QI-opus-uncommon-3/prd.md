# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문 시 포인트를 적립해 주는 기능이 없다.
- **목표:** 주문 1건의 적립 포인트를 계산하는 순수 함수를 `src/pricing/points.ts`에 만든다. 규칙은 [domain.md 포인트 적립 규칙](../../context/domain.md#포인트-적립-규칙-0030)이 단일 소스다.
- **비목표:** 포인트 잔액 저장·사용(차감)·소멸, 적립 상한, 최소 주문금액 조건, 영속화, HTTP API. (Q7 답 "알아서" → 계산만으로 결정)

## 원문 요구사항 (요청 그대로)
1. 결제 금액의 1%를 포인트로 적립합니다.
2. 쿠폰을 쓴 주문은 적립을 좀 줄여 주세요.
3. VIP 회원은 더 많이 적립해 주세요.
4. 포인트는 1포인트 단위(정수)입니다.
5. 코드는 `src/pricing/points.ts`에 만들어 주세요.

## 질문과 답 (2026-10-08 요청자 답변)
> 원문 1번의 "결제 금액"은 Q1 답에 따라 **상품 합계(subtotal)**로 읽는다. 원문과 답이 다르면 답이 기준이다.

| # | 질문 | 답 |
| --- | --- | --- |
| Q1 | 적립 기준 금액 | 쿠폰 할인 전 상품 합계(`subtotal`). 배송비 제외, 할인도 빼지 않음 |
| Q2 | 소수점 처리 | 반올림 (0.5 이상 올림) |
| Q3 | 쿠폰 사용 시 감액 | 적립하지 않음 (0포인트) |
| Q4 | VIP 적립 | 적립률 3배 (1% → 3%) |
| Q5 | VIP + 쿠폰 | 줄이지 않고 3% 그대로 |
| Q6 | 회원 정보 | `{ grade: "VIP" \| "NORMAL" }`를 따로 받음. 입력은 `PriceBreakdown` + 회원 정보, 함수 이름 자유 |
| Q7 | 범위 | 정한 것 없음 → **적립 포인트 계산만** (잔액·사용·상한·최소 주문금액 없음) |
| Q8 | 쿠폰 사용 판정 | `PriceBreakdown.discount > 0` |
