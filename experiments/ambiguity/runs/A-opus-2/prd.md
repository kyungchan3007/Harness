# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문 시 포인트를 적립해 주는 기능이 없다.
- **목표:** 주문의 결제 금액을 기준으로 적립 포인트를 계산하는 순수 함수를 `src/pricing/points.ts`에 만든다. 규칙은 [domain.md](../../context/domain.md)에 먼저 고정한다.
- **비목표:** 포인트 잔액 저장·사용·소멸, 쿠폰 할인 금액 계산(0003), 회원 등급 판정.

## 미결 — 요청자 확인 필요 (확정 전 BUILD 금지)

원문에 수치·기준이 없는 항목. 지어내지 않고 요청자에게 묻는다.

1. **쿠폰 주문 감액 폭:** "좀 줄여" — 몇 %로? (예: 적립률 0.5%, 또는 기본 적립의 50%)
2. **VIP 적립 폭:** "더 많이" — 몇 %로? (예: 2%)
3. **쿠폰 + VIP 동시:** 둘 다 해당하면 어떻게 합치나? (곱하기 / 더하기 / 한쪽 우선)
4. **기준 금액:** "결제 금액"은 domain.md의 `total`(배송비 포함)인가, 할인 후 상품 금액(`subtotal − discount`, 배송비 제외)인가?
5. **정수 처리:** 1포인트 미만은 버림(floor)인가, 반올림인가?
6. **"쿠폰을 쓴 주문"의 판정:** 현재 도메인에는 쿠폰(0003)이 없다. `discount > 0`이면 쿠폰 주문으로 볼지, 쿠폰 사용 여부를 별도 입력으로 받을지?
