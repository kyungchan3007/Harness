# 0030 — 주문 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문해도 포인트가 쌓이지 않는다. 요청에는 기본 적립률(1%)만 숫자로 있고, 쿠폰 감액·VIP 가산·끝수 처리·적립 기준 금액은 정해지지 않았다.
- **목표:** 결제 결과(`PriceBreakdown`)와 회원 등급·쿠폰 사용 여부로 적립 포인트(0 이상의 정수)를 계산하는 순수 함수 `src/pricing/points.ts`.
- **비목표:** 포인트 잔액 저장·사용·소멸, 쿠폰 할인 계산 자체(0003), 회원 등급 판정.

## 요청 원문 (사용자 대화, 2026-10-05)
- 결제 금액의 1%를 포인트로 적립합니다.
- 쿠폰을 쓴 주문은 적립을 좀 줄여 주세요.
- VIP 회원은 더 많이 적립해 주세요.
- 포인트는 1포인트 단위(정수)입니다.
- 코드는 `src/pricing/points.ts`에 만들어 주세요.

## 미정 — 사용자 확인 필요 (확정 전 BUILD 금지)
1. **쿠폰 감액량:** "좀 줄여" = 얼마? (예: 적립률 0.5%)
2. **VIP 가산량:** "더 많이" = 얼마? (예: 적립률 2%)
3. **쿠폰 + VIP 동시:** 둘 다 해당하면? (예: 곱셈 — 2% × ½ = 1%, 또는 덧셈·우선순위)
4. **기준 금액:** "결제 금액"이 domain.md의 `total`(배송비 포함)인가, 배송비를 뺀 `subtotal − discount`인가?
5. **끝수 처리:** 1포인트 미만은 버림·반올림·올림 중 무엇? (예: 버림)
