# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문 후 고객이 포인트를 적립해야 하는데, 현재 그 기능이 없다.
- **목표:** 결제 금액의 1%를 포인트로 적립하는 기능을 만든다. 쿠폰 사용 시 적립률을 줄이고, VIP 회원은 더 많이 적립하는 규칙을 포함한다.
- **비목표:** 포인트 사용, 포인트 잔액 관리, 포인트 만료, 이력 조회.

- [x] 쿠폰을 사용한 주문은 적립률이 0.5%이다
- [x] VIP 회원은 기본 1.5%, 쿠폰 적용 시 0.75%를 적립한다
