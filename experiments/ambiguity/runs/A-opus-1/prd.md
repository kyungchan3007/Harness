# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문 결제 후 고객에게 돌려줄 포인트 적립 규칙이 없다.
- **목표:** `src/pricing/points.ts`에서 주문 1건의 적립 포인트(정수)를 계산한다.
  - 기본: 결제 금액의 1%
  - 쿠폰을 쓴 주문: 적립을 줄인다 — **얼마나? (미정, Q2)**
  - VIP 회원: 더 많이 적립한다 — **얼마나? (미정, Q3)**
  - 포인트는 1포인트 단위 정수
- **비목표:** 포인트 잔액·사용·소멸, 회원 등급 판정, 쿠폰 할인액 계산(0003).
