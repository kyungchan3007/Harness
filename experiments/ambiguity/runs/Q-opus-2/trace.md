# 0030 — 포인트 적립 — Trace

에이전트가 **작업하는 동안** 직접 남기는 과정 기록입니다. 도구 호출 전체는 hooks가 `trace.auto.jsonl`에 자동으로 남깁니다(`pnpm trace 0030`으로 확인).
직접 기록에는 자동 기록이 못 남기는 것, 즉 **판단과 이유, 막힘, 되돌림**을 씁니다.

| 순서 | 단계 | 한 일 | 판단·이유 |
| --- | --- | --- | --- |
| 1 | CLAIM | 이슈 #1·브랜치 `task/0030-points`는 이미 있음. TASKS에 0030 행 추가 | 사용자가 이슈·브랜치를 지정함 |
| 2 | CLAIM | `gh issue view 1` 권한 거부 → 세션의 요청문을 request.md로 저장 | 원문 고정을 위해. 이슈 본문과 같은지는 확인 필요로 prd에 표기 |
| 3 | DEFINE | domain.md·price-cart.ts 확인 후 모호점 8개를 prd "확인 필요"로 정리 | "좀 줄여"·"더 많이"는 양이 없음. 결제 금액(total)에 배송비 포함 여부, 반올림 방식, 쿠폰(0003 미구현)·VIP(등급 개념 없음) 판정 기준도 문서에 없음 |
| 4 | DEFINE | status=blocked, 코드 작성 안 함 | 사용자 지시: 모호하면 추측 말고 질문. 답변 받으면 domain.md 규칙 → Acceptance → 구현 순으로 재개 |
