# 0030 — 주문 시 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문 후 포인트 적립 기능이 없어서 고객이 구매 혜택을 받을 수 없다.
- **목표:** 주문의 결제 금액을 기준으로 포인트를 계산하고 적립하는 기능을 만든다. 쿠폰 사용 시 적립을 감소시키고, VIP 회원은 증가시킨다. 규칙은 [domain.md](../../context/domain.md)의 포인트 규칙을 단일 소스로 한다.
- **비목표:** 포인트 사용, 포인트 조회, 포인트 히스토리, 영속화, HTTP API.
- **역할 분리:** on

## 애매한 곳·가정

- 쿠폰 사용 시 적립 감소량: 기본 적립의 20% 감소 (기본 1% → 0.8%) — (가정)
- VIP 회원 적립 증가량: 기본 적립의 50% 증가 (기본 1% → 1.5%) — (가정)
- 최소 포인트: 반올림 후 0포인트도 허용 (최소 1포인트 요구 없음) — (가정)
- VIP와 쿠폰 중복: 둘 다 적용 시 곱셈 (1% × 0.8 × 1.5 = 1.2%) — (가정)
- 반올림 규칙: Math.round 표준 반올림 (0.5 이상 올림) — (가정)
- VIP 상태 인자: 호출자(0005 주문 서비스)가 전달 — (확인 필요)
- 쿠폰 사용 여부: boolean 옵션으로 호출자가 명시 전달 — (가정)
