# 0030 — 포인트 적립 기능 — PRD

- **이슈:** #1

## 개요

주문 완료 시 회원 등급에 따라 포인트를 자동으로 적립하는 기능입니다.

## 기능 요구사항

### 1. 기본 적립 규칙
- 결제 금액(`total`)의 1%를 포인트로 적립
- 포인트는 정수 단위 (1포인트 미만은 0.5 이상이면 올림)

### 2. 쿠폰 사용 시 (NORMAL 회원)
- 쿠폰을 사용한 주문(discount > 0)은 포인트를 적립하지 않음 (0포인트)

### 3. VIP 회원
- 적립률이 3배 (1% → 3%)
- 쿠폰 사용 여부와 관계없이 VIP 적립률(3%)이 적용됨

## 입력/출력

### 입력
- `priceBreakdown: PriceBreakdown` - 가격 계산 결과 (subtotal, discount, shipping, total)
- `member: { grade: "VIP" | "NORMAL" }` - 회원 정보

### 출력
- `points: number` - 적립 포인트 (정수, 0 이상)

## 계산 예시

| 회원등급 | 결제금액 | 쿠폰 | 계산식 | 적립 |
|---------|--------|------|--------|------|
| NORMAL  | 100,000원 | 없음 | 100,000 × 1% = 1,000 | 1,000P |
| NORMAL  | 100,000원 | 사용 | 0 | 0P |
| VIP     | 100,000원 | 없음 | 100,000 × 3% = 3,000 | 3,000P |
| VIP     | 100,000원 | 사용 | 100,000 × 3% = 3,000 | 3,000P |
| NORMAL  | 1,500원  | 없음 | 1,500 × 1% = 15 | 15P |
| NORMAL  | 1,333원  | 없음 | 1,333 × 1% = 13.33 → 13 | 13P |
| NORMAL  | 1,335원  | 없음 | 1,335 × 1% = 13.35 → 13 | 13P |
| NORMAL  | 1,336원  | 없음 | 1,336 × 1% = 13.36 → 13 | 13P |
| NORMAL  | 1,350원  | 없음 | 1,350 × 1% = 13.5 → 14 | 14P |

## 제약조건

- 포인트는 항상 0 이상의 정수
- 회원 등급은 "VIP" 또는 "NORMAL" 두 가지만 존재
- 함수는 `src/pricing/points.ts`에 구현
