# PRD — 포인트 적립 시스템

## 문제

사용자가 주문할 때 포인트를 적립받을 수 없습니다.

## 솔루션

결제 금액을 기준으로 포인트를 계산하여 주문에 기록합니다.

### 기본 규칙

1. **포인트 기본 적립**: 결제 금액(`total`)의 1%를 정수 포인트로 적립합니다.
   - 예: 100,000원 → 1,000포인트
   - 소수점은 버림(floor)

2. **쿠폰 사용 시 감소**: 쿠폰으로 할인받은 주문은 적립율이 낮아집니다.
   - 정확한 감소율은 SDD에서 정의합니다.

3. **VIP 회원 보너스**: VIP 회원은 기본 적립율보다 더 많은 포인트를 받습니다.
   - 정확한 배수는 SDD에서 정의합니다.
