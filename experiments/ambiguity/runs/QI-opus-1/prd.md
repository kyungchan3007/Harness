# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문 시 포인트를 적립해 주는 기능이 없다.
- **목표:** `priceCart` 결과와 회원 등급으로 적립 포인트(정수)를 계산하는 순수 함수를 `src/pricing/points.ts`에 만든다.
- **비목표:** 포인트 잔액 저장·사용(차감)·소멸, 회원 관리, 쿠폰 할인 금액 계산(0003).

## 요청 원문
- 결제 금액의 1%를 포인트로 적립합니다.
- 쿠폰을 쓴 주문은 적립을 좀 줄여 주세요.
- VIP 회원은 더 많이 적립해 주세요.
- 포인트는 1포인트 단위(정수)입니다.
- 코드는 `src/pricing/points.ts`에 만들어 주세요.

## 열린 질문과 답 (2026-10-07 요청자 답변)

| # | 질문 | 답 |
| --- | --- | --- |
| Q1 | 쿠폰 사용 시 감소폭 | 적립률 절반 (1% → 0.5%) |
| Q2 | VIP 증가폭 | 적립률 2배 (1% → 2%) |
| Q3 | VIP + 쿠폰 | VIP 2배 먼저, 쿠폰 절반 나중 (2% → 1%) |
| Q4 | 단수 처리 | 1포인트 미만 버림(내림) |
| Q5 | 적립 기준 금액 | `subtotal − discount` (배송비 제외) |
| Q6 | 쿠폰 사용 판정 | `PriceBreakdown.discount > 0` |
| Q7 | 입력 형태 | `PriceBreakdown` + `{ grade: "VIP" \| "NORMAL" }`, 함수 이름 자유 |
| Q8 | 0원 주문 | 위임받음 → 0포인트(내림 결과로 자연히 0, 예외 규칙 없음) |
