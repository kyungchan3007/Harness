프로젝트 컨텍스트를 확인했습니다. 도메인 문서에 장바구니·배송비 규칙이 정의되어 있네요. 포인트 적립 기능을 구현하기 전에, **모호한 요구사항 5가지**를 명확히 해야 합니다:

## 명확히 필요한 사항

1. **쿠폰 사용 시 적립 감소 폭** — "좀 줄여 주세요"는 구체적으로?
   - 예: 0.5% (절반)? / 0.75%? / 다른 비율?

2. **VIP 회원 적립 증가 폭** — "더 많이"는 구체적으로?
   - 예: 1.5%? / 2%? / 배수 기준?

3. **VIP 회원 판정 기준** — 회원 정보에 어떻게 표현되나?
   - 예: `Order`의 필드 이름? / `Customer` 객체 여부? / 등급 문자열?

4. **정책 조합 로직** — 쿠폰 + VIP 동시 적용 시?
   - 예: 기본 1% → VIP로 2% → 쿠폰으로 1.5%? (순차 적용)
   - 또는: 별도 계산 후 합산?

5. **적립 기준 금액** — 다음 중 어디?
   - 전체 결제 금액(`total`)?
   - 할인 후 상품 금액(`subtotal - discount`)?
   - 배송비 제외?

6. **반올림 규칙** — 결과가 정수가 아닐 때?
   - 예: 12,345원의 1%는 123.45원 → 123? 124? 123.45로 저장 불가?(정수만 가능)

이 6가지를 먼저 결정하면 `prd.md`를 정확히 작성할 수 있습니다. 어떻게 하면 좋을까요?
