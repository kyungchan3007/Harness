# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문 결제 금액에 따라 포인트를 적립하는 규칙이 없다.
- **목표:** 가격 계산 결과(`PriceBreakdown`)와 회원 등급을 받아 적립 포인트(0 이상의 정수)를 계산하는 순수 함수를 `src/pricing/points.ts`에 만든다. 규칙은 [domain.md](../../../context/domain.md)의 "포인트 적립 규칙 (0030)".
- **확정된 답 (요청자, 2026-10-07):**
  - 기준 금액 = `subtotal − discount`(배송비 제외), 내림, 쿠폰 사용 주문은 적립률 절반(1% → 0.5%), VIP는 2배(1% → 2%)
  - 쿠폰 사용 여부 = `discount > 0`. 입력은 `PriceBreakdown`과 `{ grade: "VIP" | "NORMAL" }`. 함수 이름은 자유
  - VIP + 쿠폰 = VIP 2배 먼저, 그다음 절반 (2% → 1%)
- **위임받아 정한 것:** 적립 기준 금액이 0이면 0포인트(빈 장바구니 포함). 범위는 계산 함수까지이고 잔액·사용·환불 회수는 제외.
- **비목표:** 포인트 잔액 관리·사용(차감)·환불 시 회수, 회원 등급 저장소, 쿠폰 계산 자체(0003), 주문 모델(0005).
