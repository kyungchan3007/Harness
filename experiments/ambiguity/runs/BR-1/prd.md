# 0030 — 포인트 적립 기능 — PRD

- **이슈:** #1

## PRD
- **문제:** 고객이 주문할 때 포인트를 적립받을 수 없어 재구매 동기가 약하다.
- **목표:** 결제 금액을 기반으로 포인트를 적립하는 기능을 만든다. 쿠폰 사용 여부와 VIP 회원 여부에 따라 적립 포인트가 변한다. 규칙은 [domain.md](../../context/domain.md)가 단일 소스다.
- **비목표:** 포인트 환불, 포인트 소비·사용, 회원 로그인·인증, 영속화, HTTP API.

## Acceptance
- [x] 포인트 계산이 domain.md의 포인트 규칙 1~4를 지킨다 (규칙마다 테스트 1개 이상)
- [x] 결제 금액의 1%를 기본 포인트로 적립한다 (경계값: 100원 → 1포인트, 99원 → 0포인트)
- [x] 쿠폰을 사용한 주문은 기본 포인트의 50%만 적립한다
- [x] VIP 회원은 기본 포인트의 1.5배를 적립한다 (쿠폰과 중복 적용 가능)
- [x] 포인트는 항상 정수다 (내림: `Math.floor`)
- [x] `src/pricing/points.ts`에 `earnPoints(total, options)` 함수가 있다
- [x] `pnpm check` ALL PASS
