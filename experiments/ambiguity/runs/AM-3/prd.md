# 0030 — 포인트 적립 — PRD

## PRD
- **이슈:** #1
- **문제:** 고객이 주문 후 포인트를 적립받지 못한다.
- **목표:** 결제 금액을 기반으로 포인트를 자동 적립하는 기능을 구현한다. 할인과 회원 등급에 따라 적립률을 조정한다.
- **비목표:** 포인트 사용, 포인트 소멸, 영속화, HTTP API.

## 애매한 곳·가정
- "쿠폰을 쓴 주문은 적립을 좀 줄여 주세요" — 할인 금액의 1%를 포인트에서 제외 (할인받은 금액만큼 포인트 차감) (가정)
- "VIP 회원은 더 많이 적립해 주세요" — 기본 적립량의 2배 (가정)
- 포인트 최소값 — 0 이상으로 정규화 (가정)
