# 0033 — 포인트 적립 — PRD

- **이슈:** #1

## PRD
- **문제:** 고객이 주문했을 때 결제 금액 기반으로 적립할 포인트를 계산할 수 없다.
- **목표:** 포인트 적립 규칙을 domain.md에 정의하고, 결제 금액과 고객 등급·쿠폰 사용 여부에 따라 적립 포인트를 계산하는 순수 함수를 구현한다.
- **비목표:** 포인트 차감, 포인트 사용, 포인트 만료, 포인트 조회 API, 영속화.

## Acceptance
- [ ] 포인트 적립 규칙 1~4가 domain.md에 추가되었다
- [ ] `calcPoints(total, options)` 순수 함수가 `src/pricing/points.ts`에 있다
- [ ] 결제 금액의 1%가 기본 포인트다 (정수 내림)
- [ ] 쿠폰 사용 주문은 적립률이 0.5%로 줄어든다 (정수 내림)
- [ ] VIP 회원은 2배를 받는다 (다른 조건과 중복 가능, 정수 내림)
- [ ] 모든 경계값(0원, 999원, 1000원, 1001원, 99999원, 100000원)을 포함한 테스트가 있다
- [ ] `pnpm check` ALL PASS
