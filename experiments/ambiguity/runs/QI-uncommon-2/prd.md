# 0030 — 포인트 적립 — PRD

## PRD
- **이슈:** #1
- **문제:** 주문 후 고객의 로열티를 높이기 위해 포인트 적립 기능이 필요하다.
- **목표:** 주문 시 결제 금액을 기준으로 포인트를 적립한다. 쿠폰 사용, VIP 회원 여부에 따라 적립률을 조정한다. 규칙은 [domain.md](../../context/domain.md)에 추가된다.
- **비목표:** 포인트 사용, 포인트 만료, 포인트 거래 내역, 포인트 환전.

## 규칙 (Domain)
1. **기본 적립률:** 결제 금액(`total`)의 1%를 포인트로 적립한다.
2. **쿠폰 사용 시:** 포인트를 적립하지 않는다(0포인트). 단, VIP 회원은 제외.
3. **VIP 회원:** 결제 금액의 3%를 적립한다. 쿠폰 사용 여부와 무관하게 3% 적립.
4. **포인트 단위:** 1포인트 이상은 정수. 소수점 이하는 반올림(0.5 이상 올림).

## Acceptance
- [x] `src/pricing/points.ts`에 `calculatePoints(total, options)` 함수 구현
  - `options`: `{ isVip?: boolean, hasCoupon?: boolean }`
- [x] 규칙 1~4를 반영한 테스트 (각 규칙마다 1개 이상)
  - 기본 적립: 100원 → 1포인트, 1,000원 → 10포인트
  - 경계값: 49원 → 0포인트(반올림), 50원 → 1포인트
  - 쿠폰 일반: 1,000원 쿠폰 사용 → 0포인트
  - 쿠폰 VIP: 1,000원 쿠폰 사용 → 30포인트(VIP 3%)
  - VIP 일반: 1,000원 → 30포인트
- [x] `pnpm check` ALL PASS
