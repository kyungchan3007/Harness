# 0030 — 포인트 적립 — PRD

- **이슈:** #1

## 개요

주문 완료 시 회원에게 포인트를 적립하는 기능. 결제 금액 기반 적립률을 적용하되, 쿠폰 사용 여부와 회원 등급(VIP/일반)에 따라 달라집니다.

## 기능 요구사항

### 기본 적립률
- **일반 회원**: 결제 금액의 1%
- **VIP 회원**: 결제 금액의 3% (일반 회원의 3배)

### 쿠폰 적용 규칙
- **일반 회원 + 쿠폰**: 0 포인트 (적립하지 않음)
- **VIP 회원 + 쿠폰**: 그대로 3% 적립 (쿠폰 영향 없음)

### 포인트 단위
- 포인트는 1포인트 단위(정수)
- 소수점 포함 계산 결과는 0.5 이상이면 올림, 미만이면 내림

### 입력 사양
- **결제 정보**: PriceBreakdown 객체
  - `subtotal`: 상품 합계 (원)
  - `discount`: 할인액 (원, 쿠폰 할인 포함)
  - `shipping`: 배송비 (원)
  - `total`: 결제 금액 (원) = subtotal - discount + shipping
- **회원 정보**: `{ grade: "VIP" | "NORMAL" }`
- **쿠폰 판단**: `discount > 0`이면 쿠폰 사용으로 간주

### 완료 조건
1. `src/pricing/points.ts`에 포인트 계산 함수 구현
2. 모든 케이스(일반/VIP, 쿠폰 없음/있음)에 대해 정확히 계산
3. `pnpm check` 통과
4. TypeScript 타입 정의 포함

## 예시

| 상황 | 결제금액 | 기본 계산 | 결과 |
| --- | --- | --- | --- |
| 일반, 쿠폰X | 10,000원 | 10,000 × 1% = 100 | 100포인트 |
| 일반, 쿠폰O | 10,000원 | 적립 안 함 | 0포인트 |
| VIP, 쿠폰X | 10,000원 | 10,000 × 3% = 300 | 300포인트 |
| VIP, 쿠폰O | 10,000원 | 10,000 × 3% = 300 | 300포인트 |
| 일반, 쿠폰X | 3,333원 | 3,333 × 1% = 33.33 | 33포인트 (내림) |
