## 명확히 필요한 사항

1. **쿠폰 할인 정도**: "적립을 좀 줄여"는 구체적으로 얼마인가요?
   - 예: 50% 감소 (1% → 0.5%)?
   - 예: 절반 감소?
   - 예: 고정 감소량?

2. **VIP 회원 포인트**: "더 많이"는 구체적으로 얼마인가요?
   - 예: 2배 (1% → 2%)?
   - 예: 1.5배?
   - 예: +0.5 포인트%포인트?

3. **포인트 계산 시 반올림**: 정수 단위인데 계산 결과가 소수점이면?
   - 예: 10,000원 주문 → 100포인트 (1%) - 정확함
   - 예: 10,000원 + 0.3% 추가 → 130포인트인가 129포인트인가?
   - 올림/내림/반올림 중 어느 방식?

4. **쿠폰 + VIP 중첩**: 둘 다 적용되면 순서는?
   - 예: (기본 1% × VIP 배수) 후 쿠폰 감소?
   - 예: (기본 1% - 쿠폰 감소) × VIP 배수?

5. **입력 데이터**: 결제 금액, 쿠폰 사용 여부, VIP 여부를 함수에 어떻게 전달할지?
   - 함수 시그니처 예시가 있나요?

이 부분들을 명확히 해주면 `prd.md`(요구사항)와 `sdd.md`(설계)를 작성하고 구현을 진행하겠습니다.

## 요청자

1. 쿠폰을 쓴 주문은 포인트를 적립하지 않습니다(0포인트).
2. VIP는 적립률 3배입니다 (1% → 3%).
3. 1포인트 미만은 반올림합니다(0.5 이상이면 올림).
4. VIP는 쿠폰을 써도 줄이지 않고 VIP 적립률 3% 그대로 적립합니다.
5. 쿠폰을 썼는지는 priceCart 결과(PriceBreakdown)의 discount가 0보다 큰지로 판단합니다. 쿠폰 할인은 discount로 들어옵니다. 회원 정보는 { grade: "VIP" | "NORMAL" } 형태로 따로 받습니다. 입력은 priceCart 결과(PriceBreakdown: subtotal·discount·shipping·total)와 회원 정보 { grade: "VIP" | "NORMAL" }입니다. 함수 이름은 자유입니다.
