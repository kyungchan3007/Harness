# 0030 — 포인트 적립 기능 — PRD

- **이슈:** #1

## PRD

- **문제:** 회원 재구매를 유도할 동기가 없다.
- **목표:** 주문 완료 시 포인트를 적립한다. 결제 금액을 기준으로 하되, 쿠폰 사용 여부와 회원 등급에 따라 변동한다.
- **비목표:** 포인트 사용, 포인트 조회, 포인트 환급, 포인트 유효기간.

## 요구사항 — 확정

1. **기본 적립률:** 결제 금액(total)의 **1%**를 포인트로 적립한다.
2. **쿠폰 사용:** 적립률을 절반으로 줄임 (1% → **0.5%**)
3. **VIP 회원:** 적립률 **2배** (1% → **2%**)
4. **VIP + 쿠폰 동시 적용:** VIP 2배를 먼저 적용(2%)한 후 쿠폰으로 절반을 줄임 (**1%**)
   ```
   기본 1% → [VIP면 2배] → [쿠폰 사용하면 절반]
   ```
5. **소수점 처리:** 1포인트 미만은 버림(floor)
   - 예: 123.45 → 123포인트
6. **포인트 단위:** 모든 포인트는 정수(1포인트 단위)
7. **코드 위치:** `src/pricing/points.ts`
