## 요청자

1. 적립 기준은 쿠폰 할인 후 상품 금액(subtotal − discount)입니다. 배송비는 빼고 계산합니다.
2. 1포인트 미만은 버립니다(내림).
3. 쿠폰을 쓴 주문은 적립률을 절반으로 줄입니다 (1% → 0.5%).
4. 쿠폰을 썼는지는 priceCart 결과(PriceBreakdown)의 discount가 0보다 큰지로 판단합니다. 쿠폰 할인은 discount로 들어옵니다. 입력은 priceCart 결과(PriceBreakdown: subtotal·discount·shipping·total)와 회원 정보 { grade: "VIP" | "NORMAL" }입니다. 함수 이름은 자유입니다.
5. VIP는 적립률 2배입니다 (1% → 2%).
6. 회원 정보는 { grade: "VIP" | "NORMAL" } 형태로 따로 받습니다. 입력은 priceCart 결과(PriceBreakdown: subtotal·discount·shipping·total)와 회원 정보 { grade: "VIP" | "NORMAL" }입니다. 함수 이름은 자유입니다.
7. VIP가 쿠폰을 쓰면 VIP 2배를 먼저 적용하고 쿠폰으로 절반을 줄입니다 (2% → 1%).
8. 그 부분은 따로 정한 게 없으니 알아서 정해 주세요.
