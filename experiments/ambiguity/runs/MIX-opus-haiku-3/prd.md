# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문 시 포인트를 적립해 주는 규칙이 없다. 최초 요청("결제 금액의 1%", "쿠폰 주문은 좀 줄임", "VIP는 더 많이")은 기준 금액·감액량·판정 방법이 모호해서, 질문 Q1~Q8로 요청자 답을 받아 확정했다(아래 "확정된 답").
- **목표:** 주문 1건의 적립 포인트를 계산하는 순수 함수를 `src/pricing/points.ts`에 만든다. 규칙은 [domain.md](../../context/domain.md) "포인트 적립 규칙 (0030)"이 단일 소스다.
- **비목표:** 포인트 잔액·원장·영속화, 포인트 사용(결제 차감), 주문 취소 시 회수, 적립 상한·최소 결제 금액, 쿠폰 금액 계산(0003), VIP·NORMAL 외 등급.

## 확정된 답 (요청자, 2026-10-07)

| # | 질문 | 답 |
| --- | --- | --- |
| Q1 | 적립 기준 금액 | `subtotal − discount`. 배송비 제외 |
| Q2 | 정수 처리 | 1포인트 미만 내림 |
| Q3 | 쿠폰 주문 감액 | 적립률 절반 (1% → 0.5%) |
| Q4 | 쿠폰 사용 판정 | `PriceBreakdown.discount > 0` |
| Q5 | VIP 적립량 | 적립률 2배 (1% → 2%) |
| Q6 | 회원 정보 입력 | `{ grade: "VIP" \| "NORMAL" }`을 `PriceBreakdown`과 따로 받음. 함수 이름 자유 |
| Q7 | VIP + 쿠폰 | VIP 2배 먼저, 쿠폰 절반 나중 (2% → 1%) |
| Q8 | 범위·상한·최소 금액 | "알아서 정해 달라" → **에이전트 결정:** 계산만 한다. 상한·최소 결제 금액 없음. 잘못된 입력은 거부. 근거는 [sdd.md](sdd.md) |
