# 0034 — 포인트 적립 — PRD

- **이슈:** #1

## PRD
- **문제:** 주문 시 포인트 적립 기능이 없어 고객 충성도를 높일 방법이 없다.
- **목표:** 주문의 결제 금액 기준으로 포인트를 적립하되, 쿠폰 사용과 VIP 등급에 따라 차등 적립한다. 포인트 계산 모듈을 `src/pricing/points.ts`에 구현한다.
- **비목표:** 포인트 사용(환불), 포인트 만료, 등급 관리, 포인트 잔액 조회.

## 적립 규칙
1. **기본 적립률:** 결제 금액의 1%
   - 예: 100,000원 주문 → 1,000 포인트
2. **쿠폰 할인 시:** 적립률 절반 (0.5%)
   - 예: 100,000원 중 20,000원 할인 → 80,000원 결제 → 400 포인트
3. **VIP 회원:** 적립률 2배 (2%)
   - 예: VIP 회원 100,000원 결제 → 2,000 포인트
4. **VIP + 쿠폰:** VIP 2배를 먼저 적용하고 쿠폰으로 절반 (1%)
   - 예: VIP 회원이 100,000원을 쿠폰으로 결제 → 2% → 1% → 1,000 포인트
5. **포인트 단위:** 정수(1포인트 미만은 버림)
   - 예: 99,999원 결제 → 999.99 → 999 포인트

## 애매한 곳·가정
- 쿠폰 할인률 절반으로 정함 — (확인됨: 쿠폰 1% → 0.5%)
- VIP 보너스 2배로 정함 — (확인됨: VIP 1% → 2%)
- VIP + 쿠폰은 순서대로 적용: VIP 2배 먼저, 그 다음 쿠폰 절반 — (확인됨: 2% → 1%)
- 포인트는 floor 적용 (round 아님) — (확인됨: 내림)
- 이슈는 기존 #1 사용 — (가정) 사용자가 "따로 정한 게 없다"고 했으므로 새 이슈 불필요로 판단
