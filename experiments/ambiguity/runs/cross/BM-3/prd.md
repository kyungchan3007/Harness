# 0030 — 포인트 적립 기능 — PRD

- **이슈:** #30

## PRD

- **문제:** 현재는 주문 후 적립되는 보상이 없다. 고객 충성도를 높이기 위해 주문 금액에 따른 포인트 적립 기능이 필요하다.
- **목표:** 주문 결제 시 결제 금액을 기준으로 포인트를 적립하고, 회원 등급과 쿠폰 사용 여부에 따라 적립 비율을 조정한다. 규칙은 [domain.md](../../context/domain.md)가 단일 소스다.
- **비목표:** 포인트 사용, 포인트 이력 조회, 포인트 유효 기간, 적립 기한 관리, HTTP API.
- **역할 분리:** on

## 기능

- **기본 규칙:** 결제 금액의 1%를 포인트로 적립한다.
- **쿠폰 할인 적용:** 쿠폰을 사용한 주문의 경우 적립 비율을 70%로 감소시킨다.
- **VIP 회원 추가:** VIP 회원인 경우 적립 비율을 1.5배 늘린다.
- **정수 단위:** 포인트는 항상 1포인트 단위의 정수이며, 소수점 이하는 버린다(내림).
- **구현 위치:** `src/pricing/points.ts`

## 애매한 곳·가정

- **쿠폰 사용 시 감소율이 몇 %인가** — 70% 적립 (30% 감소)로 설정 (원문 "좀 줄여" 해석) (가정)
- **VIP 회원 시 증가율이 몇 배인가** — 1.5배 적립 (50% 추가)로 설정 (원문 "더 많이" 해석) (가정)
- **쿠폰과 VIP가 동시에 적용되는가** — 네, 두 배수를 곱함 (기본값 × 0.7 × 1.5 = 105%) (가정)
- **회원 등급은 몇 가지인가** — 기본(Regular)과 VIP 두 가지 (가정)
- **포인트 계산은 어느 계층에서 호출되는가** — 미정, 구현 단계에서 결정하고 테스트로 검증 (확인 필요)
