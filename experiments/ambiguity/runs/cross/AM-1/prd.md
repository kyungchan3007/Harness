# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **브랜치:** `task/0030-points`

## PRD
- **문제:** 주문 완료 후 구매 금액에 따라 포인트를 적립할 방법이 없다.
- **목표:** 결제 금액을 기반으로 포인트를 계산하고 적립하는 기능을 만든다. 규칙은 [domain.md](../../context/domain.md)를 단일 소스로 한다.
- **비목표:** 포인트 사용·차감, 포인트 환급, 포인트 유효기간, 영속화, HTTP API.

## 애매한 곳·가정
- 쿠폰 사용 시 적립 감소 정도 — **50% 감소** (1% → 0.5%)로 정함. 정책상 쿠폰 할인으로 이익이 줄어든 만큼 적립도 축소. (가정)
- VIP 회원 적립률 배수 — **2배**로 정함. 일반 고객 1%에서 VIP는 2%, 쿠폰 사용 시는 1%. (가정)
- 소수점 포인트 처리 — **내림(floor)**으로 정함. 예: 159원의 1%는 1.59포인트 → 1포인트. (가정)
