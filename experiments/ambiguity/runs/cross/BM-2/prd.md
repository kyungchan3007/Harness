# 0030 — 포인트 적립 — PRD

## PRD
- **문제:** 주문 후 고객 로열티를 유지할 포인트 적립 메커니즘이 없다.
- **목표:** 결제 금액 기반 포인트 적립 함수를 만든다. 기본 1% 적립에 VIP 배율·쿠폰 할인 시 감소를 적용하고, 포인트는 정수로 반올림한다. 규칙은 [domain.md](../../context/domain.md)의 포인트 섹션이 단일 소스다.
- **비목표:** 포인트 소비(환급·할인), 누적·차감 영속화, HTTP API.
- **이슈:** #1

## 역할 분리: on
- **설계자(Designer):** prd.md, sdd.md, domain.md 섹션 작성
- **구현자(Builder):** src/pricing/points.ts 구현
- **검사자(Verifier):** verdict.md, 테스트 케이스 검증

## 애매한 곳·가정
- 쿠폰 감소율 — "좀 줄여" (원문) → 적립률 50% 감소 (1% → 0.5%) (가정: 쿠폰 사용 시 고객 만족도 이미 높으므로 포인트 유인 완화)
- VIP 배율 — "더 많이" (원문) → 1.5배 (1% → 1.5%) (가정: 상위 고객층 로열티 인센티브)
- 반올림 규칙 — 미명시 (원문) → Math.round (반올림) (가정: 상거래 업계 표준, 공정성)
- 계산 순서 — 미명시 (원문) → 기본율 → VIP 배율 → 쿠폰 감소 → 반올림 (가정: 논리적 계층 구조)
