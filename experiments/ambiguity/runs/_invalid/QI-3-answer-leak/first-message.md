## 명확히 필요한 부분

현재 요청에서 다음이 명확하지 않습니다:

1. **쿠폰 할인율**  
   "쿠폰을 쓴 주문은 적립을 좀 줄여 주세요" → 얼마나 줄일까요?  
   예: 50%, 30%, 0%?

2. **VIP 회원 적립율**  
   "VIP 회원은 더 많이 적립해 주세요" → 기본 1%에서 얼마나 더?  
   예: 2%, 1.5%, 3%?

3. **VIP 판정 기준**  
   주문 객체에 회원 등급/플래그가 있나요? 어떤 필드로 판정하나요?

4. **쿠폰 판정 기준**  
   할인이 있는 모든 주문이 "쿠폰을 쓴 주문"인가요? 아니면 특정 쿠폰 타입만?

5. **반올림 방식**  
   1% 계산 결과가 소수점일 때는?  
   예: 1,234원 × 1% = 12.34포인트 → 12 or 13?
