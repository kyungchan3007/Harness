## 명확히 필요한 사항

### 1. 쿠폰 할인 시 포인트 감소율
"쿠폰을 쓴 주문은 적립을 좀 줄여 주세요" — 구체적으로 얼마나 줄일까요?
- 예: 쿠폰 사용 시 포인트를 **50%만** 적립?
- 아니면 **0포인트** (포인트 적립 불가)?
- 아니면 다른 비율?

### 2. VIP 회원 포인트 증가율
"VIP 회원은 더 많이 적립해 주세요" — 구체적으로 얼마나 더 적립할까요?
- 예: **2배** 적립?
- 아니면 **1.5배**?
- 아니면 **추가 보너스 포인트**(예: +100 포인트)?

### 3. VIP 회원 판단 기준
Order나 User 객체에 VIP 여부를 나타낼 필드가 있나요? 있다면 필드명은?
- 예: `isVip`, `memberType: 'vip' | 'regular'`, `grade`?

### 4. 쿠폰 정보 전달 방식
쿠폰 사용 여부를 어떻게 알 수 있나요?
- PriceBreakdown의 `discount` 필드로 판단? (discount > 0이면 쿠폰 사용?)
- 아니면 별도의 `couponApplied` 플래그?

### 5. 포인트 반올림 규칙
결제금액의 1%를 계산할 때, 소수점이 나오면 어떻게 처리할까요?
- 예: 1000원의 1% = 10포인트, 1050원의 1% = 10.5포인트 → **올림**? **버림**? **반올림**?

### 6. 함수 인터페이스
`priceCart()`처럼 순수 함수로 만들어야 할까요, 아니면 다른 형태를 원하나요?
- 입력: PriceBreakdown, User 정보?
- 출력: Won (포인트 정수값)?

이 부분들을 명확히 해주시면 PRD를 작성하겠습니다.
