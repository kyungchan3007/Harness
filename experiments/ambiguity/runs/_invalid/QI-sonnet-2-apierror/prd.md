# 0030 — 포인트 적립 — PRD (초안: 답변 대기)

- **이슈:** #1
- **문제:** 주문하면 결제 금액의 1%를 포인트로 적립하고 싶다. 쿠폰 사용 주문은 적립을 줄이고, VIP는 더 많이 적립한다. 포인트는 정수 단위. 코드는 `src/pricing/points.ts`.
- **목표:** 위 적립 규칙을 도메인 규칙(domain.md)으로 고정하고 `src/pricing/points.ts`에 구현한다.
- **비목표:** (답변 후 확정) 포인트 사용·차감·소멸·환불 시 회수

## 열린 질문 (답이 오기 전에는 sdd·구현 금지)

1. **쿠폰 주문 감소폭:** "좀 줄여"는 얼마인가? (예: 적립률 1% → 0.5%, 또는 적립액 50% 등) 쿠폰 종류(정액/정률)마다 다른가?
2. **VIP 증가폭:** "더 많이"는 얼마인가? (예: 2%, 또는 1.5배) VIP 등급은 하나뿐인가, 여러 단계인가?
3. **쿠폰 + VIP 동시:** 둘 다 해당하면 어떻게 조합하나? (곱하기 / 덧셈 / 한쪽 우선)
4. **적립 기준 금액:** "결제 금액"은 domain.md의 `total`(= subtotal − discount + shipping)인가? 배송비를 제외한 금액(subtotal − discount)이어야 하나?
5. **정수 처리:** 1% 계산 결과가 소수일 때 내림 / 반올림 / 올림 중 무엇인가? (예: 결제 12,350원 → 123 or 124)
6. **VIP·쿠폰 사용 여부 입력:** 코드에서 어떻게 알 수 있나? 쿠폰 사용 = `discount > 0`으로 봐도 되나, 아니면 별도 입력(쿠폰 객체/플래그)인가? 쿠폰(0003)은 아직 구현 전이고 `priceCart`는 `discount` 숫자만 받는다. VIP 여부는 어디서 오나(함수 인자?)
7. **함수 형태:** `priceCart`의 결과(`PriceBreakdown`)에 포인트를 넣을까, `points.ts`에 별도 순수 함수로 둘까?
8. **경계:** 결제 금액 0원(빈 장바구니·전액 할인)은 0포인트면 되나? 환불·취소 시 회수는 이번 범위 밖이 맞나?
