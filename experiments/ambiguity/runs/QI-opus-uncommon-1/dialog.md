2. 1포인트 미만은 반올림합니다(0.5 이상이면 올림).

## AI

포인트 적립 기능을 만들었고, 기록을 정리한 뒤 다시 돌린 `pnpm check`도 ALL PASS입니다(테스트 113개). 아직 커밋하지 않았고, `pnpm issue-sync`로 이슈 #1도 갱신하지 않았습니다.

**규칙** (규칙의 기준 문서인 `domain.md`에 "포인트 적립 규칙 (0030)"으로 먼저 적고 구현했습니다)
- 상품 합계(`subtotal`)를 기준으로 적립합니다. 배송비는 넣지 않고 할인 금액도 빼지 않습니다.
- 일반 회원은 1%, VIP는 3%입니다.
- 일반 회원이 쿠폰을 쓰면(`discount > 0`) 0P입니다. VIP는 쿠폰을 써도 3% 그대로입니다.
- 1포인트 미만은 반올림합니다. 예를 들어 10.5는 11P, 10.49는 10P입니다.
- 맡겨 주신 두 가지는 이렇게 정했습니다.
  - Q8: 상품 합계가 0원이면 0P, 적립 상한은 없습니다. 규칙에서 자연스럽게 나오는 결과라 새 규칙을 만들지 않았습니다.
  - Q9: 쿠폰 기능(0003)보다 먼저 진행했습니다. 쿠폰 사용 여부를 `discount`만 보고 판단하므로 0003과 상관없이 동작합니다.

**코드:** `src/pricing/points.ts`의 `earnPoints(breakdown, { grade })`
- 반올림은 `Math.round(subtotal * 0.01)` 대신 정수로만 계산했습니다(`floor((합계×% + 50) / 100)`). 소수 곱셈은 10.5처럼 딱 반인 값에서 결과가 어긋날 수 있어서입니다.
- 금액이 음수나 소수이거나, VIP·NORMAL이 아닌 등급이 들어오면 `RangeError`를 냅니다.
- 테스트 8개를 `points.test.ts`에 넣었습니다. 규칙마다 하나 이상이고, 반올림 경계값(0.5와 0.49, VIP 34.5)도 확인합니다.
