# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문하면 포인트를 적립해 주는 기능이 없다.
- **목표:** `priceCart` 결과와 회원 등급으로 적립 포인트를 계산하는 순수 함수를 `src/pricing/points.ts`에 만든다. 규칙은 [domain.md](../../context/domain.md#포인트-적립-규칙-0030)가 단일 소스다.
- **비목표:** 포인트 잔액 저장·사용(차감)·만료·취소 시 회수, 회원 등급 판정 로직, 쿠폰 계산(0003), HTTP API.

## 원문 요청
- 결제 금액의 1%를 포인트로 적립합니다.
- 쿠폰을 쓴 주문은 적립을 좀 줄여 주세요.
- VIP 회원은 더 많이 적립해 주세요.
- 포인트는 1포인트 단위(정수)입니다.
- 코드는 `src/pricing/points.ts`에 만들어 주세요.

## 질문과 답 (2026-10-08 요청자 답변)

| # | 질문 | 답 |
| --- | --- | --- |
| Q1 | 적립 기준 금액 | 쿠폰 할인 전 상품 합계(subtotal). 배송비 제외, 할인 금액도 빼지 않음 — 원문 "결제 금액"을 대체 |
| Q2 | 소수점 처리 | 반올림(0.5 이상 올림) |
| Q3 | 쿠폰 사용 시 감액 | 적립하지 않음(0P) |
| Q4 | 쿠폰 사용 판정 | `PriceBreakdown.discount > 0` |
| Q5 | VIP 적립 | 적립률 3배(1% → 3%) |
| Q6 | VIP + 쿠폰 | 줄이지 않고 3% 그대로 |
| Q7 | 회원 정보 | `{ grade: "VIP" \| "NORMAL" }`를 따로 받음. 입력은 `PriceBreakdown` + 회원 정보 |
| Q8 | 0원·상한 | 위임받음 → 상품 합계 0원이면 0P, 상한 없음 (규칙상 자연스러운 결과, 추가 규칙 안 만듦) |
| Q9 | 0003보다 먼저 진행 | 위임받음 → 진행. 쿠폰 여부는 discount로만 보므로 0003과 독립 |
