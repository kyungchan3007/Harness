# 0030 — 포인트 적립 — PRD

- **이슈:** #1
- **문제:** 주문 시 포인트를 적립해 주는 기능이 없다.
- **목표:** `priceCart` 결과와 회원 등급으로 주문 1건의 적립 포인트를 계산하는 순수 함수를 `src/pricing/points.ts`에 만든다. 규칙은 [domain.md 포인트 적립 규칙 (0030)](../../../context/domain.md#포인트-적립-규칙-0030).
- **비목표:** 포인트 사용·잔액·소멸, 영속화, 회원 등급 산정, 쿠폰 할인 금액 계산(0003).

## 원문 요구사항 (대화로 받은 요청 그대로 옮김 — `pnpm request 1`은 git remote가 없어 실패, request.md 미생성)

1. 결제 금액의 1%를 포인트로 적립
2. 쿠폰을 쓴 주문은 적립을 "좀" 줄임
3. VIP 회원은 "더 많이" 적립
4. 포인트는 1포인트 단위(정수)
5. 코드는 `src/pricing/points.ts`

## 질문과 답 (2026-10-07, 요청자 답변)

| # | 질문 | 답 |
| --- | --- | --- |
| Q1 | "결제 금액"은 어느 값? | 쿠폰 할인 후 상품 금액 `subtotal − discount`. 배송비 제외 |
| Q2 | 소수점 처리 | 1포인트 미만 버림(내림) |
| Q3 | 쿠폰 시 얼마나 줄이나 | 적립률 절반 (1% → 0.5%) |
| Q4 | 쿠폰 사용 판정 | `PriceBreakdown.discount > 0`. 입력은 `PriceBreakdown` + `{ grade: "VIP" \| "NORMAL" }`, 함수 이름 자유 |
| Q5 | VIP 얼마나 더 | 적립률 2배 (1% → 2%) |
| Q6 | 회원 등급 입력 | `{ grade: "VIP" \| "NORMAL" }`로 따로 받음 |
| Q7 | VIP + 쿠폰 | VIP 2배 먼저, 그다음 절반 (2% → 1%) |
| Q8 | 0원·1% 미만·상한 | 위임 → **에이전트 결정:** 0원·1포인트 미만은 0포인트(내림 규칙의 자연스러운 결과), 상한 없음 |
| Q9 | domain.md에 추가 | 위임 → **에이전트 결정:** 추가함 (도메인 단일 소스 원칙) |
